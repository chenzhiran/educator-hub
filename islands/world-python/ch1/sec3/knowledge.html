🔁 1. 循环 (Loop)

THE MAGIC OF REPETITION

01

✨ 重复动作的魔法

循环就像一个自动魔法咒语！
想象一下，如果你要拍100下皮球，不需要说100次“拍球”，只需要说：“重复拍球 100 次”。
它让计算机自动帮我们做重复的苦力活。

🏀
Looping...
❌ 没有循环 (好累!)
hero.moveRight()
hero.moveRight()
hero.moveRight()
... (写100遍?)
✅ 使用循环 (轻松!)
while True:
    hero.moveRight()

⏳ 2. while 循环

"WHILE... DO..."

02

🤔 "当...的时候"

while 的意思就是“当...的时候”。
就像妈妈说：“当(while) 作业没写完，就一直写！”
只要那个条件是成立的，循环就会一直继续下去。

while
条件成立
➡️
重复做事 🔄
# 基本结构
while 条件:
    # 重复执行的代码
    hero.moveRight()

♾️ 3. True & while True

FOREVER LOOP

03

✅ 永远成立的真话

True 是一个特殊的词，意思是“真的”、“对的”。
while True 就像一个永动机！因为条件永远是“真”的，所以它永远不会停下来。

🎡

像摩天轮一样永远转动

while True: # 永远循环
    hero.moveUp()
    hero.moveRight()
⬆️ 只要没有停止命令，
这两行代码会无限重复！

📏 4. 缩进 (Indentation)

THE QUEUING RULE

04

📐 代码的排队规则

在 Python 中，缩进非常重要！
建议统一使用 4个空格，不要混用 Tab 和空格 让代码向右排队。
只有缩进了的代码，才属于循环的“身体部分”，会被重复执行。

while True:
hero.moveUp()
hero.moveRight()
hero.say("我在外面!") ← 循环外；无限循环不结束时到不了这里

📦 5. 代码块 (Code Block)

BODY OF THE LOOP

05

🧱 循环的“身体”

所有缩进在一起的代码，组成了一个代码块。
它们就像一个团队，要么一起执行，要么一起不执行。
循环会一遍又一遍地运行整个代码块。

while True:
⬅️ 这是
代码块
hero.moveUp()
hero.moveRight()
hero.moveDown()
# 循环会重复执行框里的所有内容

🎮 6. 循环控制

INFINITE & CONTROL

06

♾️ 无限循环 (Infinite Loop)

停不下来的循环！
就像一首单曲循环的歌。
while True 就是最常见的无限循环。

🎛️ 循环控制

给循环定规矩！
比如：“重复 5 次”或者“直到碰到墙壁”。
这样循环就不会永远跑下去了。

⚡ 7. 循环的威力

THE POWER OF LOOPS

07

❌ 没有循环 (太长了!)

hero.moveUp(2)
hero.moveRight(2)
hero.moveDown()
hero.moveLeft()
hero.moveUp(2)
hero.moveRight(2)
hero.moveDown()
hero.moveLeft()
hero.moveUp(2)
... (还有好多行)
🆚

✅ 使用循环 (真简洁!)

while True:
    hero.moveUp(2)
    hero.moveRight(2)
    hero.moveDown()
    hero.moveLeft()

只需要 5 行代码！🎉
