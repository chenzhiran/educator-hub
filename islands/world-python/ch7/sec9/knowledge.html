一、While 循环 & 嵌套循环

🤡 无限循环 (While True)
像“今天这集动画片没播完，就一直重复”。
主循环 (Main Loop) 控制大节奏。
🎎 嵌套循环 (Nested Loop)
外层：遍历所有敌人。
内层：只要这个敌人还有血，就一直打。
攻击次数 ≈ 敌人数量 × 每个血量 
while True:
    enemies = hero.findEnemies()
    index = 0
    
    # 外层：一个个看
    while index < len(enemies):
        enemy = enemies[index]
        
        # 内层：死磕到底
        while enemy.health > 0:
            hero.attack(enemy)
            
        index += 1

五、累加求和 Accumulator

💰 ➕ 📝

想象你有一个“金币记账本”。

一开始是 0，每看到一个硬币，就把它的价值 加 进去。

totalValue += coin.value
就是 total = total + value 
def sumCoins(coins):
    total = 0 # 初始为0
    index = 0
    
    while index < len(coins):
        coin = coins[index]
        
        # 👇 累加器
        total += coin.value
        
        index += 1
        
    return total
