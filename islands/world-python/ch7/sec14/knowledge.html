🔄 循环家族 (Loops)

🚂 1. While 循环
while hero.gold > 20:
    hero.summon("soldier")
小火车：“只要轨道上有糖果(条件满足)，我就继续前进！”
适合：不知道要循环多少次时。
📋 2. For 循环
for friend in hero.findFriends():
    hero.command(friend, "attack")
小班长：“点名啦！自动检查每一个同学。”
适合：处理列表里的每一个东西。

📦 数据处理 (Data)

🗝️ 3. 字典 (Dictionary)
target = {"x": 50, "y": 40}
魔法宝箱： 有标签(x, y)和宝藏(50, 40)。
用来存详细信息。
👬 4. 列表 (List)
soldiers = ["士兵1", "士兵2"]
points[0] = {"x": 33, "y": 42}
排队的小朋友： 按编号排队(0, 1, 2...)。
用来存一堆东西。

🚦 智能决策 (Conditions)

🚥 5. 条件判断
if enemy:
    hero.attack(enemy)
else:
    hero.move(point)
交通警察： 红灯(有敌人)就停下攻击，绿灯(没敌人)就前进。
👮‍♂️ 6. 多重条件
if enemy and enemy.team == "ogres":
    hero.attack(enemy)
安检门： 必须满足所有条件(有票? 是本人? 身高够?)才能通过！

🧮 数学运算 (Math)

➕ 7. 坐标运算
# 向右移动一小步
newX = friend.pos.x + 0.35
告诉朋友：“从你现在的位置，往右挪 0.35 步。”
⚖️ 8. 比较运算
if enemy.health > mostHealth:
    toughest = enemy
比身高： 谁的数字大，谁就是冠军！用来找最强敌人。

🗺️ 对象与位置 (Objects)

💳 9. 对象属性
enemy.health  # 生命值
enemy.team    # 队伍
enemy.type    # 类型
看身份证： 姓名、年龄、住址...了解敌人的一切。
📍 10. 位置系统
friend.pos.x  # 横坐标 (左右)
friend.pos.y  # 纵坐标 (上下)
棋盘坐标： X是排数，Y是列数，合起来就是精确位置！

🛠️ 实用工具 (Helpers)

🏭 11. Range 函数
for i in range(4):
    hero.summon("soldier")
数字工厂： 你说“生产4个”，工厂就造出编号 0,1,2,3。
🔢 12. Len 函数
count = len(hero.findFriends())
计数器： 班长快速点人头：“1,2,3...总共8个同学！”

🧠 高级编程思维

🏆 13. 寻找最大值
best = None
maxH = 0
for e in enemies:
    if e.health > maxH:
        best = e
选冠军： 记住当前最厉害的，看到更厉害的就换掉！
🎎 14. 循环嵌套
while True:         # 外层：永远监控
    for f in friends: # 内层：检查每个朋友
        # ...
俄罗斯套娃： 大圈套小圈，外层负责“永远”，内层负责“所有”。
