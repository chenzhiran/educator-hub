1. while 循环 (Loop)

当 (while) 条件为真，就一直做。

while count < 5:
  attack()
  count += 1 # 计数器
"一定要有让条件变假的代码(比如 count += 1)，否则就是死循环！"

3. 列表与索引 (List & Index)

列表 (List) 是一排排好队的东西。

索引 (Index) 是它们的编号，从 0 开始。

enemies = hero.findEnemies()
first = enemies[0]
second = enemies[1]

len(list)：列表有多长（有几个元素）。

遍历模板 (Traversal)

用 index 变量像手指一样，一个一个指过去。

index = 0
while index < len(enemies):
  enemy = enemies[index]
  hero.attack(enemy)
  index += 1
