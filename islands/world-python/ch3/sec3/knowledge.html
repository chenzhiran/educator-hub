我是小小守门员

01

想象你在守球门，面对飞来的球，你必须做出选择：

  • 👉 如果 球在左边 → 向左扑救
  • 👉 否则 (球在右边) → 向右扑救
这就是双分支选择！就像站在岔路口，一定要选择一条路走！

选择题答题卡

02

if-else 就像你在做选择题：

“如果 A 选项是正确的，就涂 A；
否则 (A 不对)，就涂 B！”

if 条件成立:
    执行方案 A # 选这条路
else:
    执行方案 B # 否则选这条

B

生活中的例子

03

看看这个关于天气的例子：

# 如果下雨就带伞，否则戴帽子！
if 下雨了:
    带上雨伞()
else:
    戴上帽子()

总有一个动作会被执行，不可能两个都做，也不可能两个都不做！

双分支 vs 单分支

05
单分支 (if)
只关心“如果成立怎么办”。
如果不成立，就什么都不做，继续往下走。
双分支 (if-else)
关心“成立怎么办” 和 “不成立怎么办”。
一定要选一边！
