用户界面 (UI) 🖥️

User Interface

👀 怎么让玩家看到分数？
就像汽车仪表盘显示速度一样，游戏需要一个界面来告诉玩家当前的状态。
我们使用 ui.track() 把藏在代码里的数字（比如打败了多少怪物）展示在屏幕上。

👇 屏幕上会显示这个 👇
💀 Defeated: 5
⏳ Time: 12s
# 1. 设置生存时间
game.addSurviveGoal(20)

# 2. 生成一个怪物生成器
spawner = game.spawnXY("generator", 50, 50)
spawner.spawnType = "munchkin"

# 3. 关键一步！把"击败数"显示出来
ui.track(game, "defeated")

生存目标 ⏱️

Survival Goal

🛡️ 活下去就是胜利！
并不是所有游戏都要打败魔王。有时候，只要坚持住不倒下就算赢。
在这一关，我们给玩家定了一个小目标：坚持20秒！

⚠️ 挑战模式：
敌人会源源不断涌来，保护好你的血条！
# 告诉游戏：玩家只要活过20秒就算赢
game.addSurviveGoal(20)

# 生成我们的英雄
player = game.spawnPlayerXY("knight", 15, 15)

# 稍微增强一点属性，不然太容易挂了
player.maxHealth = 100
player.attackDamage = 10

数据库 💾

Database

📝 永远记住你！
普通的变量重启游戏就没了。但数据库 (db) 就像一个永久的笔记本。
它可以记录你玩了多少次、总共赢了多少局。哪怕你关掉电脑明天再来，数据还在！

🎮 ➡️ 💾
# 每次运行代码，都在"plays"这个格子里加1
db.add("plays", 1)

# 把数据库里的记录显示在屏幕上
ui.track(db, "plays")

# 第一次玩显示: 1
# 第二次玩显示: 2
# ...以此类推
🗄️

Ecosystem Simulation

1. 食人魔 (Ogres) 是捕食者 🐺

3. 硬币 (Coins) 是食物 🌿
通过调整它们的速度和繁殖规则，观察这个世界是平衡发展还是走向灭绝！
