迷宫元素 🌲

Maze Elements

🧐 一键生成迷宫？
想不想一键生成一个复杂的森林迷宫？不用一棵树一棵树的种！
只要一行代码，系统就会根据你提供的“种子数字”自动生成路径和障碍。

# 这里的数字就是"种子"，换个数字迷宫就变了 game.spawnMaze("forest", 1234567890) # 生成玩家 "决斗者" game.spawnPlayerXY("duelist", 12, 13) # 设置出口目标 game.addMoveGoalXY(60, 59)

对象属性 🔥

Game Object Attributes

🔧 万物皆可改
游戏里的每一个东西（对象）都有属性。
比如这个“火焰喷射器”，它有一个特殊的属性叫 direction（方向）。

我们可以把它从横向喷射改成纵向喷射，构建火焰陷阱！

# 生成一个火焰喷射器，叫它 fs1 fs1 = game.spawnXY("fire-spewer", 12, 25) # 默认是横向(horizontal)喷的 # 我们把它改成垂直方向(vertical) fs1.direction = "vertical"
↕️ Vertical = 垂直 | ↔️ Horizontal = 水平
🔥
🎮 游戏开发1 Level 16

敌人生成器 💀

Enemy Generator

🏭 怪物工厂
如果你想让敌人源源不断地出来，你需要一个“生成器(generator)”。
它就像一个怪物的传送门，会按照一定的时间间隔自动把怪物吐出来。

💡 策略： 我们可以用发光石(lightstone)把这些生成的骷髅引开！

# 在 (45, 35) 放一个怪物生成器 game.spawnXY("generator", 45, 35) # 生成器会自动工作... # 哪怕你不写额外代码，它也会一直刷怪 # 用发光石吸引它们的注意力 game.spawnXY("lightstone", 25, 45)
🏭
🎮 游戏开发1 Level 17

赋予怪物生命 🤖

Non-Player Behavior

🧠 它们在想什么？
通过设置 behavior（行为）属性，我们可以控制怪物在游戏里的表现。是像疯子一样乱跑，还是像保镖一样站岗？

  • 🏃 Scampers: 看到人就到处乱跑
  • 😡 AttacksNearest: 谁离得近就打谁
  • 🛡️ Defends: 站在原地防守
# 1. 这个骷髅只会乱跑 skeleton3.behavior = "Scampers" # 2. 这个食人魔是个狂战士 ogre1.behavior = "AttacksNearest" # 3. 这个弓箭手负责守家 archer1.behavior = "Defends"
🧠
