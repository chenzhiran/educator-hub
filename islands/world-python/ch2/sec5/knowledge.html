游戏元素的生成 🏗️

Game Element Spawning

🌍 建造你的世界！
生成（Spawning）就像变魔术，让物体凭空出现在地图上。
我们需要使用 game.spawnXY() 命令。这不仅能造人，还能造宝箱、钥匙、甚至会源源不断吐出怪物的“生成器”！

🔑 小任务：
把钥匙藏在角落，把宝箱锁起来！
# 1. 召唤主角 Raider
player = game.spawnPlayerXY("raider", 28, 60)
player.attackDamage = 10

# 2. 放置一个锁住的宝箱
game.spawnXY("locked-chest", 44, 28)

# 3. 把银钥匙藏在别的地方
game.spawnXY("silver-key", 43, 60)

# 4. 创建一个怪物生成器 (每4秒生一个)
gen = game.spawnXY("generator", 26, 44)
gen.spawnType = "munchkin"
gen.spawnDelay = 4
