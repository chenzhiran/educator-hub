排除检查官：!=

!= 就像一个挑剔的检查官，他在问：
“这两个东西不一样吗？”

  • ✅ 如果不一样 → 回答 True (是的，不一样)
  • ❌ 如果一样 → 回答 False (不是，它们一样)
if enemy.type != "burl":
  hero.attack(enemy)
"除了 Burl，其他的都可以打！"
🙅‍♂️

"NOT EQUAL!"

⚖️

双胞胎：== vs !=

它们就像一对性格相反的双胞胎。

==
相等运算符
问：一样吗？
🍎 == 🍎 (True)
!=
不等于运算符
问：不同吗？
🍎 != 🍊 (True)
"apple" != "apple" # False
👯
🔍

实战：避开巨人

在游戏里，我们不想攻击友好的 "burl"。

while True:
  enemy = findNearestEnemy()
  if enemy:
    if enemy.type != "burl":
      attack(enemy)

逻辑：
1. 找到人了吗？(if enemy)
2. 是不是 burl？(if type != "burl")
3. 不是 burl 才打！

👾
💡

布尔逻辑 (Boolean Logic)

!= 也是布尔逻辑的一个开关。

True != True False
True != False True
False != True True
"只有两边状态不一样时，才返回真！"

思维训练：排除法

有时候，告诉计算机“不要做什么”比“要做什么”更简单！

# 正向思维 (麻烦)
if type == "A" or type == "B" or type == "C":
  attack()

# 逆向思维 (简单)
if type != "D":
  attack()
"只要不是那个特定的，其他的通通拿下！"
🌪️

为什么是 "burl"?

在 CodeCombat 中，"burl" 是森林里的树人巨人。

  • 🕊️ 中立生物：如果你不打它，它就不打你。
  • 💪 极其强大：如果你打了它，你可能会被秒杀！
所以我们用 != "burl" 来保护自己，不要惹怒巨人！
