实战 I：斜线飞行

同时改变 X 和 Y，就能走出斜线！

while True:
  # 向左上飞: X减, Y加
  newX = hero.pos.x - 6
  newY = hero.pos.y + 4
  hero.moveXY(newX, newY)

轨迹：↖️ 左上角

实战 II：垂直追踪

根据敌人的高度 (Y坐标) 来调整自己的位置。

if enemy.pos.y > hero.pos.y:
  # 敌人在上，我也向上
  hero.moveXY(x, y + 4)
else:
  # 敌人在下，我也向下
  hero.moveXY(x, y - 4)
"就像电梯一样，跟着目标上下移动。"

相对位置判断

比较坐标大小，就能知道方位：

  • 👉 enemy.x > hero.x : 敌人在右边
  • 👈 enemy.x < hero.x : 敌人在左边
  • 👆 enemy.y > hero.y : 敌人在上边
  • 👇 enemy.y < hero.y : 敌人在下边
(x>, y>)
📏

距离计算 (Math)

虽然有 distanceTo()，但用坐标差也能算距离。

# 水平距离 (绝对值)
dist_x = abs(enemy.pos.x - hero.pos.x)

# 垂直距离
dist_y = abs(enemy.pos.y - hero.pos.y)
"abs() 是绝对值函数，把负数变正数。"
