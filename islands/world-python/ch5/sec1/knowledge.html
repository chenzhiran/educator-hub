字符串加法：拼接术

像拼乐高积木一样，用 + 号把两段文字连起来。

"Friend " + "Alice"
# 结果: "Friend Alice"

在游戏里，这很有用：

hero.say("Hello " + friend.id)
"Hello"
+
"World"
点击积木拼接
🖨️

字符串乘法：复制术

就像魔法复印机！把字符串乘以数字，就能复制多份。

"Ha" * 3
# 结果: "HaHaHa"
"Danger! " * 2 = "Danger! Danger! "
📄
x 3
➗

整数四则运算

数字的魔法比较直接：

+加法 (合体)
-减法 (拿走)
*乘法 (倍增)
/除法 (平分)
total = 5 + 3 # 8
share = 10 / 2 # 5
🧮
💥

乘方运算：超级复制

这是更厉害的魔法！成倍成倍地增长。

# 3 的 2 次方 (3²)
power = 3 ** 2
# 结果: 9

注意是两个星号 ** 哦！

🧙‍♂️
点击法师施法 (3²)
📦

变量与顺序执行

变量 (Variable)：贴了标签的箱子。
顺序 (Sequence)：一步一步来，像做菜。

sum = 5 + 3 # 第一步
hero.say(sum)
sub = sum - 2 # 第二步
sum
🥇

运算符优先级

魔法规则：先乘除，后加减。

2 + 3 * 4
# 先算 3*4=12
# 再算 2+12=14

想要改变顺序？用括号 ()！

(2 + 3) * 4 # = 20
( ) > * / > + -
🦉

魔法小贴士

🚫 不要把文字和数字直接相加！
"HP: " + 100 (Python里可能需要转换)
➗ 除法可能产生小数：
5 / 2 = 2.5 (不是 2 哦)
🧙‍♀️
🎓

毕业总结

编程就是施展魔法！

用 + 连接世界，
用 * 复制力量，
用 变量 储存宝藏。
