反向大师：not

01/08

not 就像一面魔法镜子！

它会把 True (真) 变成 False (假)，反之亦然。

is_raining = True
go_out = not is_raining
# 结果：False (不能出去)
"妈妈说：如果没有下雨，就可以出去玩。"

实战：CSI 逻辑解密

02/08

Csilla 的证词逻辑很复杂：

csi = (A and B) or (B and (not C))

意思是：
要么 A和B 都是嫌疑人；
或者 B是嫌疑人，但 C 不是。

Secret B:
Secret C:
(A && B) || (B && !C)

逻辑运算符也有“地位高低”：

1. ( ) 括号 - 最高
2. not - 取反
3. and - 并且
4. or - 或者
"not 像乘法，and/or 像加减法。
但为了不晕，请多用括号！"

德摩根定律 (De Morgan)

05/08

这是逻辑世界的变形魔法：

not (A and B)
# 等价于
(not A) or (not B)

例子：
"不是(又下雨又刮风)"
= "没下雨 或者 没刮风"

🚫(🌧️ + 🌪️)
