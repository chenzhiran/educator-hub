什么是“标准操作规程” (SOP)?

在现实中，SOP 是一套标准的行动步骤：
👨‍🚒 消防员 SOP： 接警 → 穿衣 → 上车 → 出发。
👨‍⚕️ 医生 SOP： 检查呼吸 → 量血压 → 输液。

游戏代码里的 SOP：
"所有士兵一出生，就按照【这套步骤】行动！"
📜

SOP 第一步：锁定主角

谁来执行这个规程？我们要先找到他。

def fightEnemies(event):
  # event.target 是这次事件的"主角"
  unit = event.target
  # 以后都叫他 unit (单位)
  unit.attack(enemy)

就像老师点名：“这次轮到小明，大家看小明做示范。”

+
🤠
unit = event.target
⚔️

SOP 示例一：战斗

def fightEnemies(event):
  unit = event.target # 1. 确认是谁
  while True: # 2. 一直做
    enemy = unit.findNearestEnemy()
    if enemy: # 3. 有怪就打
      unit.attack(enemy)

翻译成白话就是：
“认领任务 → 只要活着 → 找敌人 → 砍他！”

1. 锁定 unit
⬇️
2. 寻找敌人
⬇️
3. 攻击 enemy
🔄 循环
🔥

SOP 示例二：集合

有时候不需要一直打仗，只需要走到指定位置。

def centerFormation(event):
  unit = event.target
  # 所有人去篝火旁集合!
  unit.moveXY(40, 36)
配合命令：
game.setActionFor("soldier", "spawn", centerFormation)

SOP 示例三：守卫林道

这个 SOP 多了一步：记住家在哪。

def defendLane(event):
  unit = event.target
  # 1. 记下出生点 X 坐标
  startX = unit.pos.x
  while True:
    enemy = unit.findNearestEnemy()
    if enemy:
      unit.attack(enemy)
    else:
      # 2. 没敌人就回家
      unit.moveXY(startX, 16)

全军出击：setActionFor

写好了 SOP，怎么发给所有人？

game.setActionFor("soldier", "spawn", fightEnemies)

这句话的意思是：
“游戏请注意：当士兵发生出生事件时，自动执行 fightEnemies 这个 SOP。”

从此你就是给全军制定规则的总指挥官！
