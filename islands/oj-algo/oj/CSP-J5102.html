📜 任务清单 (题目描述)

符文墙上刻着字符串 s，它可能是由某个更短的子串重复多次拼接而成。

你的任务：找出这个最短重复子串（最小循环节）的长度！

如果整个字符串不能由更短的子串重复构成，那答案就是字符串本身的长度。

📐 输入输出格式：
• 输入：一行字符串 s（1 ≤ |s| ≤ 105，仅含小写字母）
• 输出：一个整数，最小循环节的长度
📥 样例 1 
abbaabbaabba
📤 输出：4
"abba" 重复 3 次 = "abbaabbaabba"
📥 样例 2 
aaaaaa
📤 输出：1
"a" 重复 6 次 = "aaaaaa"

🧠 魔法道具箱 (核心图解)

🔗 什么是"循环节"？

🔍 怎么找最短循环节？——逐个试！

核心思路：从最短的长度 L=1 开始尝试，逐步增大，第一个能整除并成功匹配的 L 就是答案！

两个必要条件

条件 1：长度能整除 → n % L == 0
如果总长度 n 不能被 L 整除，那 L 个字符重复若干次绝对凑不出长度为 n 的字符串。

条件 2：内容全部匹配 → 每个字符 s[i] == s[i % L]
前 L 个字符是"模板"，后面每个字符都必须和模板里对应位置的字符一模一样。

🏆 第一个成功的 L = 4，所以答案是 4！

🔎 写法一：逐字符比较（推荐，效率高）

对于每个候选长度 L，用取余逐字符验证是否全部匹配。不需要构造新字符串，省空间、更快！

枚举 L
从 1 到 n
→
n % L == 0?
长度能整除？
→
逐字符验证
s[i] == s[i%L]?
→
全部匹配？
✅ 输出 L！
💡 为什么第一个匹配的 L 就是答案？

因为我们从 L=1 开始从小到大枚举！第一个成功的 L 就是最短的循环节。
找到后立刻输出并结束，不需要继续尝试更大的 L。

💡 为什么只枚举到 n/2？

循环节至少要重复 2 次才叫"重复"，所以循环节长度最大为 n/2。
如果在 1 ~ n/2 范围内都没找到，说明整个字符串就是"独一无二"的，答案就是 n 本身。

📘 C++ 写法一 · 知识点

  • 📏 string 的长度： s.length() 或 s.size() 返回字符串长度。
  • 🔄 取余索引技巧： s[i] == s[i % L]，利用取余让索引在 0~L-1 之间"循环"。这是处理周期性问题的经典手法。
  • 🚩 bool 标志变量： 用 ok 变量记录"是否全部匹配"，一旦发现不匹配就 break 跳出内层循环。

💻 C++ 逐字符比较代码

#include <iostream>
#include <string>
using namespace std;

int main() {
    string s;
    cin >> s;
    int n = s.length();

    // 🔎 从小到大枚举循环节长度 L
    for (int L = 1; L <= n / 2; L++) {
        // 条件1：总长度必须能被 L 整除
        if (n % L != 0) continue;

        // 条件2：逐字符检查是否全部匹配
        bool ok = true;
        for (int i = L; i < n; i++) {
            if (s[i] != s[i % L]) {
                ok = false;
                break;  // 发现不匹配，立刻放弃这个 L
            }
        }

        if (ok) {
            cout << L << endl;  // 🎉 找到最短循环节！
            return 0;
        }
    }

    // 没找到任何循环节，答案就是自身长度
    cout << n << endl;
    return 0;
}

🐍 Python 写法一 · 知识点

  • 📏 len() 求长度： len(s) 返回字符串长度。
  • 🔄 取余索引： s[i] == s[i % L] 让索引在 0~L-1 之间循环，完美匹配周期性。
  • 🐍 for-else 语法： Python 独有的 for...else——如果循环正常结束（没被 break），就执行 else 块。用来判断"全部匹配"非常优雅！

💻 Python 逐字符比较代码

s = input()
n = len(s)

# 🔎 从小到大枚举循环节长度 L
for L in range(1, n // 2 + 1):
    # 条件1：总长度必须能被 L 整除
    if n % L != 0:
        continue

    # 条件2：逐字符检查
    for i in range(L, n):
        if s[i] != s[i % L]:
            break  # 不匹配，放弃这个 L
    else:
        # 🎉 for 循环正常结束 = 全部匹配！
        print(L)
        exit()

# 没找到，答案是自身长度
print(n)

✂️ 写法二：子串拼接比较（直观好理解）

对于每个候选长度 L，直接把前 L 个字符复制 n/L 次，看拼出来的字符串是否和原串一模一样。

枚举 L
从 1 到 n/2
→
n % L == 0?
能整除？
→
拼接比较
s[:L] × k == s ?
→
匹配？
✅ 输出 L！

⚠️ 这个方法的效率问题

每次拼接和比较字符串，都会创建一个长度为 n 的新字符串。
当 n = 105 时，如果有很多候选的 L，反复创建和比较可能较慢。
Python 中字符串乘法 s[:L] * k 写起来很方便；
C++ 中需要手动拼接，建议优先用写法一的逐字符比较。

📘 C++ 写法二 · 知识点

  • ✂️ substr 截取子串： s.substr(0, L) 截取从位置 0 开始、长度为 L 的子串。
  • 🔗 字符串拼接： C++ 中用 += 反复拼接来构造重复字符串。注意每次拼接都会创建新对象，效率不如逐字符比较。
  • ⚖️ 字符串比较： t == s 可以直接比较两个 string 是否内容完全相同。

💻 C++ 子串拼接代码

#include <iostream>
#include <string>
using namespace std;

int main() {
    string s;
    cin >> s;
    int n = s.length();

    for (int L = 1; L <= n / 2; L++) {
        if (n % L != 0) continue;

        // ✂️ 取出前 L 个字符作为模板
        string pattern = s.substr(0, L);

        // 🔗 把模板重复 n/L 次
        string t = "";
        for (int j = 0; j < n / L; j++) {
            t += pattern;
        }

        // ⚖️ 拼出来的和原串一样吗？
        if (t == s) {
            cout << L << endl;
            return 0;
        }
    }

    cout << n << endl;
    return 0;
}

🐍 Python 写法二 · 知识点

  • ✂️ 切片截取： s[:L] 取前 L 个字符。Python 切片简洁优雅！
  • ✖️ 字符串乘法： s[:L] * k 直接把子串重复 k 次！这是 Python 的超级语法糖。
  • ⚖️ 直接比较： == 可以直接判断两个字符串是否完全相同。

💻 Python 子串拼接代码

s = input()
n = len(s)

for L in range(1, n // 2 + 1):
    if n % L != 0:
        continue

    # ✂️ 取前 L 个字符，重复 n//L 次
    if s[:L] * (n // L) == s:
        print(L)    # 🎉 找到了！
        exit()

print(n)

🔍 写法二执行过程 (s = "abbaabbaabba")

n = 12，从 L=1 开始尝试：
L=1： 12%1=0 ✅ → "a"×12 = "aaaaaaaaaaaa" ≠ 原串 → ❌

L=2： 12%2=0 ✅ → "ab"×6 = "abababababab" ≠ 原串 → ❌

L=3： 12%3=0 ✅ → "abb"×4 = "abbabbabbabb" ≠ 原串 → ❌

L=4： 12%4=0 ✅ → "abba"×3 = "abbaabbaabba" == 原串 → ✅ 找到了！

答案 = 4 🎉

💡 技巧和重点总结 (划重点啦)

  • 🔑 整除是前提： 循环节长度 L 必须能整除总长度 n（n % L == 0）。不满足这个条件的 L 直接跳过，大大减少无效计算！
  • 🔄 取余是核心： s[i] == s[i % L] 利用取余让索引"循环回绕"到 0~L-1 的范围。这是处理周期性问题的经典技巧，记住它！
  • 🏃 从小到大找，找到就停： 由于我们要找的是最短的循环节，从 L=1 开始枚举，第一个成功的就是答案。千万别忘了找到后就 return / exit！
  • 📏 枚举范围是 1 到 n/2： 循环节至少要重复2次，所以最大长度不超过 n/2。如果都没找到，答案就是 n（整个字符串本身就是"循环节"，只出现 1 次）。
  • 🐍 Python 独家彩蛋： s[:L] * k == s 一行就能验证，for...else 语法让代码更优雅。这些是 Python 的特色武器！
