💡 关键发现：乘积存到哪一位？

当 a 的第 i 位 × b 的第 j 位 时，结果应该加到 res 数组的第 i + j 位！

以 123 × 456 为例（翻转后：a = "321", b = "654"）
a[i] b[j] 乘积 存到 res[i+j] 含义
a[0]=3（个位）b[0]=6（个位）18res[0] += 18个×个 → 个位
a[0]=3（个位）b[1]=5（十位）15res[1] += 15个×十 → 十位

a[1]=2（十位）b[1]=5（十位）10res[2] += 10十×十 → 百位
……………
核心公式：res[i + j] += a[i] × b[j]
💡 为什么是 i + j？ 因为第 i 位代表 10ⁱ，第 j 位代表 10ʲ，它们的乘积 = 10^(i+j)，所以结果自然在第 (i+j) 位！

🔀 高精度乘法 vs 高精度加法

如果你已经学过高精度加法，那恭喜你——乘法是在加法的基础上升级的！先来看看它们的异同：

对比项 ➕ 高精度加法 ✖️ 高精度乘法
循环 单层 for 循环 双重 for 循环
核心操作 a[i] + b[i] + carry res[i+j] += a[i] × b[j]
进位处理 循环中同步处理 所有乘积累加完后统一处理
结果长度 最多 max(len_a, len_b) + 1 最多 len_a + len_b
前导零 不会有多余前导零 可能有前导零，需要去掉
💡 最大区别： 加法是"对应位相加"，乘法是"每一位和每一位都要乘一次"——所以需要双重循环，并且结果先累加到 res[i+j]，最后再统一处理进位！

⚠️ 重点攻关：前导零 & 特殊情况

🕳️
前导零陷阱
res 数组从低位到高位存放结果，高位可能有多余的 0。去前导零时，要从最高位开始往下扫，删掉连续的 0。
但注意：如果结果本身就是 0（比如 0 × 12345），至少要保留一个 "0"！不能输出空字符串！
🛡️
零乘任何数
0 × 999...9 = 0
如果输入有一个 0，结果就是 0。我们的算法会自然得出全零的 res 数组，去前导零后只剩一个 "0"。不需要特判！
res = [0, 0, 0, 5, 6]
翻转 → "65000" ❌
→ 去掉 →
去掉末尾零 → [0, 0, 0, 5, 6] 变 [5, 6]
翻转 → "65" ❌

等等！应该是反过来去掉！
翻转 res → "65000" → 去前面的0
但实际我们在翻转前去末尾0：
res 末尾的0对应高位，去掉后翻转
✅ 正确做法（代码中的写法）：
1. res 数组低位在前：[8, 8, 0, 6, 5, 0]
2. 从末尾去掉多余的 0（它们是高位的0）：[8, 8, 0, 6, 5]
3. 翻转得到最终结果：56088 ✅

📘 C++ 魔法秘籍 (知识点)

  • 📜 字符串存大数： string 存储输入，然后转成 vector<int> 的数字数组来计算。
  • 🔄 翻转函数： reverse(s.begin(), s.end()) 让个位排到最前面。
  • 📏 结果数组长度： 两个数的乘积最多 len_a + len_b 位，所以 res 数组开这么大。
  • 🔢 先乘后进位： 双重循环先把所有 a[i] * b[j] 累加到 res[i+j]，循环结束后再统一处理进位。

💻 C++ 终极法术 (代码详解)

#include <bits/stdc++.h>
using namespace std;

int main() {
    string sa, sb;
    cin >> sa >> sb;  // 📥 用字符串读入两个超大数

    int la = sa.size(), lb = sb.size();

    // 🔄 步骤一：翻转字符串，个位排到前面
    reverse(sa.begin(), sa.end());
    reverse(sb.begin(), sb.end());

    // 📦 步骤二：创建结果数组，长度 = la + lb，初始化为 0
    vector<int> res(la + lb, 0);

    // ✖️ 步骤三：双重循环，逐位相乘并累加
    for (int i = 0; i < la; i++) {
        for (int j = 0; j < lb; j++) {
            res[i + j] += (sa[i] - '0') * (sb[j] - '0');
        }
    }

    // 🔢 步骤四：处理进位（满十进一）
    for (int i = 0; i < res.size() - 1; i++) {
        res[i + 1] += res[i] / 10;  // 进位给下一位
        res[i] %= 10;               // 当前位只留个位
    }

    // 🧹 步骤五：去掉高位多余的 0（但至少保留一个 0）
    while (res.size() > 1 && res.back() == 0) {
        res.pop_back();
    }

    // 🔄 翻转输出（高位在前）
    for (int i = res.size() - 1; i >= 0; i--) {
        cout << res[i];
    }
    cout << endl;

    return 0;
}

📝 方法二：手动模拟（学习算法思想）

def main():
    sa = input().strip()
    sb = input().strip()

    la, lb = len(sa), len(sb)

    # 🔄 步骤一：翻转字符串，个位排到前面
    sa = sa[::-1]
    sb = sb[::-1]

    # 📦 步骤二：创建结果数组
    res = [0] * (la + lb)

    # ✖️ 步骤三：双重循环，逐位相乘并累加
    for i in range(la):
        for j in range(lb):
            res[i + j] += int(sa[i]) * int(sb[j])

    # 🔢 步骤四：处理进位
    for i in range(len(res) - 1):
        res[i + 1] += res[i] // 10   # 进位
        res[i] %= 10                # 留个位

    # 🧹 步骤五：去掉高位的 0（至少保留一个）
    while len(res) > 1 and res[-1] == 0:
        res.pop()

    # 🔄 翻转输出
    res.reverse()
    print(''.join(str(x) for x in res))

if __name__ == "__main__":
    main()

💡 技巧和重点总结 (划重点啦)

🌟
核心公式 res[i+j] += a[i]×b[j]： 这是高精度乘法的灵魂！a 的第 i 位 × b 的第 j 位，结果累加到 res 的第 (i+j) 位。理解了这个，整个算法就通了！
🌟
先乘后进位： 和高精度加法不同，乘法是先把所有乘积全部累加完，然后再单独一轮循环处理进位。这样代码更清晰，不容易出错！
🌟
结果数组开 len_a + len_b： 两个数相乘，结果最多有 len_a + len_b 位（比如 999 × 999 = 998001，3+3=6 位）。数组开小了就会越界！
🌟
前导零要处理： 乘法结果可能有高位多余的 0（特别是有因子为 0 时），去掉它们但至少保留一个 "0"。这是很多同学 WA 的原因！
🌟
翻转是固定套路： 输入翻转（个位到前面）→ 计算 → 去高位零 → 翻转输出。这和高精度加法一模一样，形成肌肉记忆！
