📜 任务清单 (题目描述)

n 件衣服，第 i 件湿度为 wi。每秒所有衣服自然风干 a 点湿度。

另有一台魔法烘衣机：每秒只能对准一件衣服，让它额外减少 b 点湿度（总共减少 a+b）。

目标：所有衣服湿度 ≤ 0 的最少时间。

📐 关键规则：
• 🌬️ 自然风干：每秒每件衣服减少 a 点（同时进行！）
• 🔥 烘衣机：每秒只能选一件，额外减少 b 点（该件总共减 a+b）
• 📏 数据范围：n, a, b, wi ≤ 5×105

⚡ 核心算法：二分答案 + 贪心检查

💡 关键思想：猜时间 T！

猜一个时间 T → 检验 T 秒内能否烘干所有衣服

对每件衣服：
① 自然风干 T 秒后，剩余湿度 rest = wi - a × T
② 如果 rest ≤ 0 → 已经干了，不需要烘衣机 ☀️
③ 如果 rest > 0 → 需要烘衣机 ⌈rest / b⌉ 秒 🔥

所有衣服需要的烘衣机总时间 ≤ T → T 秒可行 ✅

🔍 二分范围

📉 下界 lo = 0

最好情况：0 秒就全干了？
不太可能，但从 0 开始二分没问题。

📈 上界 hi = max(wi)

因为 a ≥ 1，所以 max(wi) 秒后
自然风干就能把最湿的衣服弄干。
不需要更多时间。

✨ check(T) 的核心公式 ✨
对每件衣服 i：
resti = wi - a × T
若 resti > 0 → need += ⌈resti / b⌉

判断：need ≤ T ?
⌈rest / b⌉ = (rest + b - 1) / b（上取整公式）
含义：烘衣机每秒额外减 b，需要 ⌈rest/b⌉ 秒才能把 rest 点湿度烘干
💡 上取整怎么理解？

rest = 5，b = 2：需要 ⌈5/2⌉ = 3 秒（减2,2,1）
rest = 4，b = 2：需要 ⌈4/2⌉ = 2 秒（减2,2）
rest = 1，b = 3：需要 ⌈1/3⌉ = 1 秒（减3足够）

公式：(rest + b - 1) / b（整数除法自动下取整，加 b-1 变上取整）

🔍 为什么这个检查方法是对的？

💡 核心洞察：烘衣机的分配可以任意！

T 秒内，烘衣机共有 T 秒可用。
每秒选哪件衣服都行，顺序无所谓。

所以关键问题是：总共需要多少秒的烘衣机时间？
• 衣服 i 自然风干后还剩 resti = wi - a×T
• 每用 1 秒烘衣机，可以额外减 b 点
• 需要 ⌈resti/b⌉ 秒才能烘干衣服 i

只要所有衣服的烘衣机需求总和 ≤ T，就一定能安排好！

✅ T 大 → 容易满足
自然风干更多 → rest 更小
需要的烘衣机时间更少
同时可用的烘衣机时间更多
双重利好！
❌ T 小 → 难以满足
自然风干不够 → rest 更大
需要更多的烘衣机时间
可用的烘衣机时间更少
双重不利！

📐 重要公式：上取整 ⌈a/b⌉

场景：剩余湿度 rest 点，烘衣机每秒减 b 点，需要几秒？

rest b rest ÷ b ⌈rest/b⌉ 实际需要 公式 (rest+b-1)/b
632.02(6+2)/3=2 ✅
732.333(7+2)/3=3 ✅
130.331(1+2)/3=1 ✅
522.53(5+1)/2=3 ✅
422.02(4+1)/2=2 ✅
(rest + b - 1) / b（整数除法）= 正确的上取整！
这个技巧在竞赛中非常常用，必须牢记！

⚠️ 细节与注意事项

🚨 细节1：使用 long long 避免溢出！

a × T 中，a 和 T 都可能达到 5×10⁵，乘积约 2.5×10¹¹ → 超过 int 范围！
C++ 中 rest 和 need 必须用 long long。
Python 自动支持大整数，不用担心。

🚨 细节2：上取整用整数公式！

⌈rest / b⌉ = (rest + b - 1) / b（整数除法）
千万不要用浮点数除法再 ceil，会有精度问题！
竞赛中整数上取整永远用这个公式。

🚨 细节3：rest ≤ 0 时不需要烘衣机！

wi - a × T 可能是负数（已经超量风干）。
此时 rest ≤ 0，说明自然风干就够了。
只有 rest > 0 的衣服才需要计入烘衣机需求。

🚨 细节4：need 累加时也要防溢出！

多件衣服的 ⌈rest/b⌉ 累加可能很大。
C++ 中 need 也要用 long long。
另外一旦 need > T 就可以提前返回 false（剪枝优化）。

📘 C++ 知识点

  • 🔍 二分答案模板： 找最小可行时间 T，hi=mid 模板。
  • 📐 上取整公式： (rest + b - 1) / b，整数除法实现上取整。
  • 📦 long long： a×T 可达 2.5×10¹¹，必须用 64 位整数。
  • ⚡ IO 加速： ios::sync_with_stdio(false)。

💻 C++ 代码

#include <iostream>
#include <algorithm>
using namespace std;

int n;
long long a, b;
long long w[500005];

// 🟢 check：T 秒内能否烘干所有衣服？
bool check(long long T) {
    long long need = 0;  // 烘衣机总共需要的时间

    for (int i = 0; i < n; i++) {
        long long rest = w[i] - a * T;  // 自然风干后剩余湿度
        if (rest > 0) {
            // 🔥 还没干，需要烘衣机 ⌈rest/b⌉ 秒
            need += (rest + b - 1) / b;
            if (need > T) return false;  // ⚡ 提前剪枝
        }
    }
    return need <= T;  // ✅ 烘衣机时间够用吗？
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    cin >> n >> a >> b;

    long long maxW = 0;
    for (int i = 0; i < n; i++) {
        cin >> w[i];
        maxW = max(maxW, w[i]);
    }

    // 🔍 二分答案：找最小的可行时间 T
    long long lo = 0, hi = maxW;
    while (lo < hi) {
        long long mid = (lo + hi) / 2;
        if (check(mid)) {
            hi = mid;       // ✅ 可行，尝试更短时间
        } else {
            lo = mid + 1;   // ❌ 不可行，增大时间
        }
    }

    cout << lo << endl;
    return 0;
}

🐍 Python 知识点

  • 🔍 二分答案： 找最小可行时间 T，hi=mid 模板。
  • 📐 上取整： (rest + b - 1) // b，Python 整除用 //。
  • ⚡ 快速 IO： 用 sys.stdin.buffer.read() 一次性读入。
  • 🐍 大整数无忧： Python 自动处理大整数。

💻 Python 代码

import sys

def main():
    data = sys.stdin.buffer.read().split()
    idx = 0

    def rd():
        nonlocal idx
        idx += 1
        return int(data[idx - 1])

    n, a, b = rd(), rd(), rd()
    w = [rd() for _ in range(n)]

    def check(T):
        """T 秒内能否烘干所有衣服？"""
        need = 0
        for x in w:
            rest = x - a * T
            if rest > 0:
                need += (rest + b - 1) // b
                if need > T:       # ⚡ 提前剪枝
                    return False
        return need <= T

    # 🔍 二分答案
    lo, hi = 0, max(w)
    while lo < hi:
        mid = (lo + hi) // 2
        if check(mid):
            hi = mid
        else:
            lo = mid + 1

    print(lo)

main()

🎯 直观理解：两种"力量"的合作

🌬️
自然风干
  • 同时作用于所有衣服
  • 每秒每件减 a 点
  • 总减量 = n × a × T
  • 威力大但均匀分配
🔥
烘衣机
  • 每秒只能选一件
  • 该件额外减 b 点
  • 总减量 = b × T（最多）
  • 威力集中，定点攻破
策略：自然风干搞定大部分 → 烘衣机补刀剩余最难搞的衣服 🎯
正因如此，只要总烘衣机需求 ≤ T 就一定可行——无论怎么安排每秒给谁

💡 技巧和重点总结 (划重点啦)

  • 🎯 二分答案思想： 猜时间 T → 检验"T 秒内烘衣机时间是否够用"。时间越长越容易满足 → 完美单调性 → 二分找最小可行 T！
  • 🔥 check 函数： 每件衣服自然风干后剩余 rest = wi - a×T。若 rest > 0，需要烘衣机 ⌈rest/b⌉ 秒。累加所有需求 ≤ T 就可行。整个 check 只需 O(n)！
  • 📐 上取整公式： ⌈x/y⌉ = (x + y - 1) / y（整数除法）。竞赛中超级常用，千万不要用浮点 ceil！
  • 🔢 long long 注意： a × T 最大约 (5×10⁵)² = 2.5×10¹¹，超过 int 范围。C++ 中 rest、need 必须用 long long。
  • ⚡ 提前剪枝： check 中一旦 need > T，立即返回 false，避免无效累加。
  • 🏔️ 二分范围： lo=0（最好 0 秒就干了），hi=max(w)（自然风干最湿的衣服，因为 a≥1 所以 max(w)/a ≤ max(w)）。约 19 轮二分 × n 次遍历 = 1 千万次操作，轻松通过！
