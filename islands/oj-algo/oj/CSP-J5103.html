关键概念："能整除"的方向

题目问的是：有多少个别人的数字 能整除 我的数字？
即：别人的数是我的因数。

例如小紫的数字是 4：
• 1 能整除 4？ 4 % 1 = 0 ✅（1 是 4 的因数）
• 2 能整除 4？ 4 % 2 = 0 ✅（2 是 4 的因数）
• 3 能整除 4？ 4 % 3 = 1 ❌（3 不是 4 的因数）
• 注意：不数自己！只数其他人。

🎯 两种解法任你选！

🐢 解法一：暴力双重循环（直觉但超时）

最直接的想法：对于每个人，遍历所有其他人，检查是否能整除。

📋 模拟过程（样例1：[2, 1, 2, 3, 4]）
i=0 (a[i]=2): 检查 j=1(1✅), j=2(2✅), j=3(3❌), j=4(4❌) → 计数=2
i=1 (a[i]=1): 检查 j=0(2❌), j=2(2❌), j=3(3❌), j=4(4❌) → 计数=0
i=2 (a[i]=2): 检查 j=0(2✅), j=1(1✅), j=3(3❌), j=4(4❌) → 计数=2
i=3 (a[i]=3): 检查 j=0(2❌), j=1(1✅), j=2(2❌), j=4(4❌) → 计数=1
i=4 (a[i]=4): 检查 j=0(2✅), j=1(1✅), j=2(2✅), j=3(3❌) → 计数=3
⚠️ 超时警报！

双重循环的时间复杂度是 O(n²)。
当 n = 105 时，需要 1010 次操作 → 严重超时！🐌
我们需要更聪明的方法……

💻 C++ 暴力代码（仅用于理解思路，会超时）

#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    int a[100005];
    for (int i = 0; i < n; i++) cin >> a[i];

    for (int i = 0; i < n; i++) {
        int cnt = 0;
        for (int j = 0; j < n; j++) {
            if (i != j && a[i] % a[j] == 0)
                cnt++;  // 别人能整除我
        }
        if (i > 0) cout << " ";
        cout << cnt;
    }
    return 0;
}
⚠️ 时间复杂度 O(n²)，n=10⁵ 时会超时！仅供理解思路！

💻 Python 暴力代码（仅用于理解思路，会超时）

⚡ 解法二：倍数传播法（正解！）

💡 核心思想：换个角度思考！

暴力法是"对每个人，找他的因数"——太慢了。
换个角度："对每个值 x，它能整除谁？——它能整除所有 x 的倍数！"

如果值 x 出现了 cnt[x] 次，那么所有 x 的倍数（2x, 3x, 4x, ...）
都能被 x 整除，所以它们的答案都要加上 cnt[x]！

这就像传播：每个值 x 把自己的出现次数"广播"给所有倍数。

w[v] 的含义是什么？
w[v] = 数组中有多少个数是 v 的因数（包括 v 自己！）

第3步：减去自己 → 最终答案

题目说"不算自己"，所以每个人的答案 = w[a[i]] − 1

a = [2, 1, 2, 3, 4]

第1个人 (a=2): w[2] − 1 = 3 − 1 = 2
第2个人 (a=1): w[1] − 1 = 1 − 1 = 0
第3个人 (a=2): w[2] − 1 = 3 − 1 = 2
第4个人 (a=3): w[3] − 1 = 2 − 1 = 1
第5个人 (a=4): w[4] − 1 = 4 − 1 = 3

输出：2 0 2 1 3 ✅
💡 为什么减 1 就对了？

w[v] 统计了数组中所有能整除 v 的数的个数。
但 v 本身也是自己的因数（v % v = 0），也被统计进去了！
题目说"不算自己"，所以减去 1 就是只算其他人的个数。

⚠️ 注意：这里减的 1 指的是"自己这个数值整除自己"，对每个人都恰好减 1 次。

📘 C++ 解法二 · 知识点

  • 📊 计数数组 cnt[]： 用 cnt[x]++ 统计每个值出现的次数。数组大小开到最大值+1。
  • 📡 倍数枚举： for (y = x; y <= maxV; y += x) 是枚举 x 的所有倍数的经典写法！步长为 x，依次访问 x, 2x, 3x, ...
  • 🧮 调和级数复杂度： 这个双重循环的总操作次数是 maxV/1 + maxV/2 + ... + maxV/maxV ≈ O(maxV × ln(maxV))，约为 O(maxV × log(maxV))。当 maxV = 106 时大约是 2000 万次，完全可行！
  • ➖ 减自己的技巧： 最后对每个 a[i]，输出 w[a[i]] - 1，巧妙地排除自身。

💻 C++ 倍数传播代码

#include <iostream>
using namespace std;

const int MAXV = 1000001;
int cnt[MAXV], w[MAXV];  // cnt: 计数, w: 因数个数
int a[100005];

int main() {
    int n, maxV = 0;
    cin >> n;

    // 📊 第1步：读入并统计每个值出现几次
    for (int i = 0; i < n; i++) {
        cin >> a[i];
        cnt[a[i]]++;
        if (a[i] > maxV) maxV = a[i];
    }

    // 📡 第2步：倍数传播
    for (int x = 1; x <= maxV; x++) {
        if (cnt[x] == 0) continue;  // 没出现过，跳过
        // 把 cnt[x] 传播给 x 的所有倍数
        for (int y = x; y <= maxV; y += x) {
            w[y] += cnt[x];
        }
    }

    // ➖ 第3步：输出每个人的答案（减去自己）
    for (int i = 0; i < n; i++) {
        if (i > 0) cout << " ";
        cout << w[a[i]] - 1;  // 不算自己！
    }
    cout << endl;

    return 0;
}

🐍 Python 解法二 · 知识点

  • 📊 列表计数： 用 cnt = [0] * (maxV + 1) 创建计数数组。也可以用 collections.Counter，但数组更快。
  • 📡 range 步长枚举倍数： range(x, maxV+1, x) 用步长 x 枚举所有倍数：x, 2x, 3x, ...
  • ⚡ 避免构造： 直接在数组上操作，不构造额外的列表，保持效率。
  • ➖ 减自己： 最后对每个 a[i]，答案是 w[a[i]] - 1。

💻 Python 倍数传播代码

import sys
input = sys.stdin.readline  # 加速读入

n = int(input())
a = list(map(int, input().split()))

maxV = max(a)

# 📊 第1步：统计每个值出现几次
cnt = [0] * (maxV + 1)
for x in a:
    cnt[x] += 1

# 📡 第2步：倍数传播
w = [0] * (maxV + 1)
for x in range(1, maxV + 1):
    if cnt[x] == 0:
        continue  # 没出现过，跳过
    # 把 cnt[x] 传播给 x 的所有倍数
    for y in range(x, maxV + 1, x):
        w[y] += cnt[x]

# ➖ 第3步：输出（减去自己）
result = []
for x in a:
    result.append(w[x] - 1)
print(*result)

🤔 为什么倍数传播是正确的？

思考本质：

对于数字 v，它的因数有哪些？就是所有能整除 v 的数。

换句话说：x 能整除 v ⟺ v 是 x 的倍数。

所以当我们处理值 x 时，x 的所有倍数都会被 x 整除！

把 cnt[x] 加到 w[倍数] 上，就是在说：
"有 cnt[x] 个值为 x 的数，它们都是这些倍数的因数。"

暴力思维 🐢
对每个人 → 扫描所有人
找谁能整除我
O(n²)
⇄
传播思维 ⚡
对每个值 → 广播给倍数
告诉它们"我是你因数"
O(maxV log maxV)

🧩 知识拓展：埃氏筛法的亲戚

这种"从 x 跳到 2x, 3x, 4x..."的枚举倍数技巧，和著名的埃拉托斯特尼筛法（筛质数）是一个套路！

🔢 埃氏筛法
从 x 开始，标记 2x, 3x, 4x... 为"非质数"
用途：筛选质数
🎯 本题方法
从 x 开始，给 x, 2x, 3x, 4x... 的 w 加上 cnt[x]
用途：统计因数个数

核心都是：for (y = x; y <= max; y += x) —— 枚举倍数的经典模板！

💡 技巧和重点总结 (划重点啦)

  • 🔄 反向思考是关键： 不要想"我的因数有哪些"，而是想"我能成为谁的因数"。从"找因数"转换为"传播倍数"，巧妙地利用了枚举倍数的高效性。
  • 📊 计数数组预处理： 先用 cnt[] 统计每个值出现的次数。这样在传播时，不需要关心具体有几个人，只需知道值和出现次数。
  • 📡 倍数枚举模板： for (y = x; y <= maxV; y += x) 是枚举 x 的所有倍数的核心代码。总复杂度约为 O(maxV × log(maxV))，比 O(n²) 高效得多！
  • ➖ 减 1 去掉自己： w[v] 包含了值 v 本身对自己的贡献。题目要求"不算自己"，所以答案是 w[a[i]] - 1。
  • 🧠 埃氏筛思想： 这道题的核心思想和埃拉托斯特尼筛法一脉相承——都是"从因数出发，标记/更新倍数"。掌握这个模板，可以解决很多类似的"因数/倍数关系"问题！
