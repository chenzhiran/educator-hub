⭐ 什么是质数？

质数（素数）= 大于 1 的整数中，只能被 1 和它自身整除的数。

✅ 质数
2, 3, 5, 7, 11, 13...
只有两个因数：1 和自己
❌ 合数
4, 6, 8, 9, 10, 12...
有三个及以上因数
⚠️ 特殊
0, 1
既不是质数也不是合数

🐢 解法一：逐个判断质数

最直觉的方法：对每个数 x，检查它有没有除了 1 和自身以外的因数。

🔎 判断单个数是否为质数

检查 x 是否为质数：只需尝试 2 到 √x 之间有没有能整除 x 的数。

为什么只到 √x？因为如果 x 有一个大于 √x 的因数 d，那么 x/d 一定小于 √x，我们早就找到了。

例：判断 7 是否为质数
√7 ≈ 2.65，只需检查 i = 2
7 % 2 = 1 ≠ 0 → 没有因数 → 7 是质数！✅

例：判断 9 是否为质数
√9 = 3，检查 i = 2, 3
9 % 2 = 1 ≠ 0
9 % 3 = 0 → 找到因数！→ 9 是合数！❌
⚠️ 效率问题

对每个数判断需要 O(√x) 时间，判断 N 个数总共需要 O(N√N) 时间。
当 N = 106 时，约需 109 次运算 → 有超时风险！
我们需要更快的方法 —— 看看解法二的"筛法"！

💻 C++ 逐个判断代码（较慢，可能超时）

#include <iostream>
#include <vector>
using namespace std;

// 🔎 判断 x 是否为质数
bool isPrime(int x) {
    if (x < 2) return false;
    for (int i = 2; i * i <= x; i++) {
        if (x % i == 0) return false;
    }
    return true;
}

int main() {
    int N;
    cin >> N;

    vector<int> primes;
    for (int i = 2; i <= N; i++) {
        if (isPrime(i)) primes.push_back(i);
    }

    cout << primes.size() << endl;
    for (int i = 0; i < primes.size(); i++) {
        if (i > 0) cout << " ";
        cout << primes[i];
    }
    cout << endl;
    return 0;
}

💻 Python 逐个判断代码（较慢，可能超时）

def is_prime(x):
    if x < 2:
        return False
    i = 2
    while i * i <= x:
        if x % i == 0:
            return False
        i += 1
    return True

N = int(input())
primes = [i for i in range(2, N + 1) if is_prime(i)]

print(len(primes))
print(*primes)

⚡ 解法二：埃拉托斯特尼筛法（正解！）

💡 核心思想：用质数去"筛掉"合数！

不是一个一个判断是不是质数，而是反过来——
从最小的质数 2 开始，把它的所有倍数标记为"合数"（划掉！）
然后找下一个没被划掉的数（它一定是质数），继续划掉它的倍数……
最后所有没被划掉的数就是质数！

就像用筛子筛沙子 🫧 —— 合数从筛孔漏下去，质数留在筛子上！

🔑 两个关键优化细节

💡 优化 1：外层循环只到 √N

如果一个合数 x ≤ N，它最小的质因数一定 ≤ √N。
所以筛到 √N 就足够了！之后没被标记的都是质数。

例如 N=30，√30 ≈ 5.47，只需处理 i = 2, 3, 5（三个质数）就够了。

💡 优化 2：从 i×i 开始标记（不是从 2×i）

当筛质数 i 时，比 i² 小的倍数已经被更小的质数筛过了！

举例：筛 i=5 时——
• 5×2=10 → 已被 i=2 筛过 ✓
• 5×3=15 → 已被 i=3 筛过 ✓
• 5×4=20 → 已被 i=2 筛过 ✓
• 5×5=25 → 第一个需要 i=5 来筛的数！

所以从 j = i * i 开始，避免重复标记，更快！

📘 C++ 埃氏筛法 · 知识点

  • 📦 bool 数组： bool isPrime[N+1] 用于标记每个数是否为质数。初始全为 true，然后把合数标记为 false。
  • 🔄 i * i <= N： 外层循环条件，等价于 i ≤ √N，但避免浮点数精度问题。
  • 📡 内层循环： for (j = i*i; j <= N; j += i) 从 i² 开始，步长 i，标记所有倍数为合数。
  • ⚡ 数组大小注意： N 最大 106，开静态数组 bool isPrime[1000001] 即可。

💻 C++ 埃氏筛法代码

#include <iostream>
#include <vector>
using namespace std;

const int MAXN = 1000001;
bool isPrime[MAXN];

int main() {
    int N;
    cin >> N;

    // 📋 第1步：初始化，假设全是质数
    for (int i = 2; i <= N; i++)
        isPrime[i] = true;
    // isPrime[0] = isPrime[1] = false; (默认就是false)

    // 🔎 第2步：埃氏筛法
    for (int i = 2; i * i <= N; i++) {
        if (isPrime[i]) {
            // i 是质数，划掉它的所有倍数
            for (int j = i * i; j <= N; j += i) {
                isPrime[j] = false;  // 标记为合数
            }
        }
    }

    // 📊 第3步：收集所有质数
    vector<int> primes;
    for (int i = 2; i <= N; i++) {
        if (isPrime[i]) primes.push_back(i);
    }

    // 📤 输出
    cout << primes.size() << endl;
    for (int i = 0; i < primes.size(); i++) {
        if (i > 0) cout << " ";
        cout << primes[i];
    }
    cout << endl;

    return 0;
}

🐍 Python 埃氏筛法 · 知识点

  • 📦 布尔列表： [True] * (N+1) 创建一个全为 True 的列表，然后把非质数标记为 False。
  • 🔄 range 三参数： range(i*i, N+1, i) 从 i² 开始，步长 i，完美枚举倍数。
  • 🐍 列表推导式： [i for i in range(2, N+1) if is_prime[i]] 一行收集所有质数，简洁优雅。
  • ⚡ int(N**0.5)： Python 中计算平方根用 N**0.5，转 int 截断小数。

💻 Python 埃氏筛法代码

import sys
input = sys.stdin.readline

N = int(input())

# 📋 第1步：初始化
is_prime = [False, False] + [True] * (N - 1)
# is_prime[0]=False, is_prime[1]=False, 其余=True

# 🔎 第2步：埃氏筛法
i = 2
while i * i <= N:
    if is_prime[i]:
        # i 是质数，划掉它的所有倍数
        for j in range(i * i, N + 1, i):
            is_prime[j] = False
    i += 1

# 📊 第3步：收集所有质数
primes = [i for i in range(2, N + 1) if is_prime[i]]

# 📤 输出
print(len(primes))
print(*primes)

💡 技巧和重点总结 (划重点啦)

  • ⭐ 质数的定义： 大于 1 的正整数中，只有 1 和自身两个因数的数。1 不是质数，2 是最小的质数（也是唯一的偶质数）。
  • 🧹 筛法核心思想： 不是一个一个判断质数，而是用质数去"淘汰"合数。从 2 开始，把它的倍数全部标为合数，然后处理下一个未被标记的数（它一定是质数），重复此过程。
  • 📐 外层只到 √N： 合数的最小质因数一定 ≤ √N，所以筛到 √N（即 i * i <= N）就够了。剩下未被标记的全是质数。
  • ⚡ 从 i² 开始标记： 筛质数 i 时，从 j = i * i 开始标记（而不是 j = 2 * i），因为比 i² 小的合数已经被更小的质数筛过了。这个优化能减少大量重复操作！
  • 🧮 复杂度魔法： 埃氏筛法的时间复杂度是 O(N log log N)，几乎接近 O(N)！处理 N = 106 仅需百万级操作，比逐个判断的 O(N√N) 快百倍！
  • 🎒 竞赛必备模板： 埃氏筛法是信息学竞赛中的基础模板，不仅用于筛质数，还能扩展到筛最小质因数、欧拉函数等。务必熟记！
