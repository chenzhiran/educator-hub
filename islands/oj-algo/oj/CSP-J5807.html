📜 任务清单 (题目描述)

N 名罪犯要分到两座监狱中。某些罪犯之间有仇恨（怨气值 c），如果他们在同一监狱就会发生冲突。

市长只看最大冲突的影响力。请你安排分配方案，使得这个最大冲突值最小。

📐 输入输出格式：
• 输入：第1行 N, M（罪犯数、仇恨对数），接下来 M 行每行 a, b, c（a 和 b 之间怨气值 c）
• 输出：一个整数——最大冲突影响力的最小值（若无冲突输出 0）
• 数据范围：N ≤ 20000，M ≤ 100000，c ≤ 109
📥 样例输入 
4 6
1 4 2534
2 3 3512
1 2 28351
1 3 6618
2 4 1805
3 4 12884
📤 输出：3512

💡 关键洞察：贪心思路

核心思想：优先处理最大的仇恨！

把所有仇恨按怨气值从大到小排序，然后逐个处理：

对于每对仇恨 (a, b)，我们尽量把 a 和 b 分到不同监狱。
如果之前的分配让 a 和 b 不得不在同一监狱（产生矛盾），
那当前的怨气值 c 就是答案！

为什么？ 因为我们是从大到小处理的，之前所有更大的仇恨都已经成功分开。
第一个无法分开的仇恨，就是最终的"最大冲突的最小值"。

🔮 什么是"扩展域并查集"？

💡 核心思想：给每个人一个"敌人分身"！

普通并查集只能表示"谁和谁是一伙的"，但这道题需要表示"谁和谁是敌人"。

解决办法：开 2 倍大小的并查集！
• 节点 i（1~N）= 罪犯 i 本身
• 节点 i+N（N+1~2N）= 罪犯 i 的"敌人域"（代表"和 i 在不同监狱的人"）

操作"把 a 和 b 分到不同监狱"：
→ union(a, b+N)：a 和 b 的敌人域合并（a 和 b 的敌人是一伙的）
→ union(b, a+N)：b 和 a 的敌人域合并

检查"a 和 b 是否被迫同一监狱"：
→ find(a) == find(b)：如果 a 和 b 已经在同一集合 → 矛盾！

💡 为什么贪心是正确的？

我们优先满足怨气值最大的仇恨对（让它们分到不同监狱）。

如果处理到怨气值为 c 的边时发现 a 和 b 必须同监狱：
• 所有怨气值 > c 的边都已经成功分开了 ✅
• 这条边的 c 就是"不可避免的最大冲突" → 答案！

如果所有边都成功分开 → 答案 = 0（没有冲突）。

💡 并查集操作详解

要分开 a 和 b（放不同监狱）：
union(a, b+N) — a 和"b 的敌人"同伙
union(b, a+N) — b 和"a 的敌人"同伙

检查 a 和 b 是否已在同一监狱：
find(a) == find(b) → 矛盾！→ 输出当前 c

为什么这样能传递约束？
如果 1↔2 分开且 1↔3 分开，那么 2 和 3 的敌人域都和 1 合并了，
所以 2 和 3 自动在同一集合里 → 同一监狱！

📘 C++ 知识点

  • 🌲 并查集模板： find(x) 路径压缩 + unite(x,y) 按秩合并，是高效处理连通性问题的标准数据结构。
  • 📡 扩展域： 开 2N 大小的并查集，节点 i+N 代表 i 的"敌人域"。这是处理"对立关系"的经典技巧。
  • 📊 sort + 自定义比较： 按结构体的某个字段降序排序。
  • ⚡ 复杂度： 排序 O(M log M) + 并查集 O(M α(N)) ≈ O(M log M)。

💻 C++ 代码

#include <iostream>
#include <algorithm>
using namespace std;

const int MAXN = 40005;  // 2 * 20000 + 5
int fa[MAXN];  // 并查集父节点

// 🌲 路径压缩的 find
int find(int x) {
    if (fa[x] != x) fa[x] = find(fa[x]);
    return fa[x];
}

// 🔗 合并
void unite(int x, int y) {
    fa[find(x)] = find(y);
}

struct Edge {
    int a, b, c;
} edges[100005];

// 📊 按怨气值从大到小排序
bool cmp(Edge &x, Edge &y) {
    return x.c > y.c;
}

int main() {
    int N, M;
    cin >> N >> M;

    // 📋 初始化并查集（2N 个节点）
    for (int i = 1; i <= 2 * N; i++)
        fa[i] = i;

    // 📥 读入所有边
    for (int i = 0; i < M; i++)
        cin >> edges[i].a >> edges[i].b >> edges[i].c;

    // 📊 按怨气值从大到小排序
    sort(edges, edges + M, cmp);

    // ⚡ 贪心处理每条边
    for (int i = 0; i < M; i++) {
        int a = edges[i].a, b = edges[i].b, c = edges[i].c;

        // 💥 检查 a 和 b 是否已在同一集合（同监狱）
        if (find(a) == find(b)) {
            cout << c << endl;  // 无法分开！这就是答案
            return 0;
        }

        // ✅ 可以分开：a 和 b的敌人 合并，b 和 a的敌人 合并
        unite(a, b + N);  // a 和 b 的敌人域是一伙的
        unite(b, a + N);  // b 和 a 的敌人域是一伙的
    }

    // 🎉 所有仇恨都成功分开，无冲突！
    cout << 0 << endl;
    return 0;
}

🐍 Python 知识点

  • 🌲 并查集实现： Python 中用列表模拟并查集。find 函数用迭代而非递归（避免 Python 递归深度限制）。
  • 📡 扩展域： 同样开 2N 大小的列表，i+N 表示 i 的敌人域。
  • 📊 排序： sort(key=lambda x: -x[2]) 按第三个元素降序。
  • ⚡ sys.stdin 加速： 大量输入时用 sys.stdin 避免超时。

💻 Python 代码

import sys
input = sys.stdin.readline

# 🌲 并查集（迭代版 find，避免递归深度问题）
def find(x):
    while fa[x] != x:
        fa[x] = fa[fa[x]]  # 路径压缩（两步跳跃）
        x = fa[x]
    return x

def unite(x, y):
    fa[find(x)] = find(y)

N, M = map(int, input().split())

# 📋 初始化并查集（2N 个节点，1-indexed）
fa = list(range(2 * N + 1))

# 📥 读入所有边
edges = []
for _ in range(M):
    a, b, c = map(int, input().split())
    edges.append((a, b, c))

# 📊 按怨气值从大到小排序
edges.sort(key=lambda x: -x[2])

# ⚡ 贪心处理每条边
ans = 0
for a, b, c in edges:
    # 💥 检查是否已在同一集合
    if find(a) == find(b):
        ans = c  # 无法分开！
        break

    # ✅ 分开：建立敌对关系
    unite(a, b + N)
    unite(b, a + N)

print(ans)

🎨 更多理解：为什么约束能自动传递？

📌 约束传递的魔法

假设有三个人 A, B, C：

第1步：A 和 B 是敌人（分开）
→ union(A, B') 和 union(B, A')
集合：{A, B'} 和 {B, A'}
第2步：A 和 C 是敌人（分开）
→ union(A, C') 和 union(C, A')
集合：{A, B', C'} 和 {B, A', C}
🎯 现在 B 和 C 在同一集合 {B, A', C} 中！
A 的两个敌人 B 和 C，自动变成了同伙（同监狱）！
这就是扩展域并查集的魔法——"敌人的敌人是朋友"自动实现！

📌 如果所有仇恨都能分开

例如只有 2 对仇恨：A↔B 和 C↔D（互不相关）

处理完所有边后，从未出现 find(a) == find(b) 的情况。

→ 答案 = 0（所有仇恨对都在不同监狱，完全无冲突！）

🧩 并查集模板速记

🌲 普通并查集
• find(x)：找 x 的根（路径压缩）
• unite(x,y)：合并 x 和 y 的集合
• 只能表示"同一组"关系
🔮 扩展域并查集
• 开 2N 大小
• i+N = i 的"敌人域"
• 能表示"对立"关系
• 敌人的敌人是朋友自动传递！

💡 技巧和重点总结 (划重点啦)

  • 🎯 问题转化： "最大冲突的最小值" → 经典的最小化最大值问题。贪心策略：优先处理最大的威胁，无法化解的就是答案。
  • 📊 排序是关键： 按怨气值从大到小排序后处理。这样第一个产生矛盾的边，就是答案。因为更大的仇恨已经全部避开了。
  • 🔮 扩展域并查集： 节点 i 是本人，i+N 是敌人域。union(a, b+N) 表示"a 和 b 分到不同监狱"。检查 find(a)==find(b) 判断是否矛盾。
  • ⚡ 复杂度优秀： 排序 O(M log M) + 并查集操作近似 O(M)。总体 O(M log M)，对 M=10⁵ 完全不是问题！
  • 🛡️ 别忘了输出 0： 如果所有仇恨对都成功分开了（循环结束没有矛盾），答案是 0——完全不会发生冲突。
