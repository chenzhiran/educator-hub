🧠 魔法道具箱 (核心图解)

这道题需要两种高精度运算的组合：高精度 × 小数（算阶乘）+ 高精度 + 高精度（累加求和）。

每次用上一次的阶乘 × 当前数！

➕ 核心技能：高精度 + 高精度

每算出一个 k!，就要把它加到总和 sum 上。这就是之前学过的高精度加法！

📌 演示：sum(33) + fact(120) = 153

sum = [3, 3]，fact = [0, 2, 1]（低位在前）

i=0: sum[0](3) + fact[0](0) + carry(0) = 3 → 留 3 进位 0
i=1: sum[1](3) + fact[1](2) + carry(0) = 5 → 留 5 进位 0
i=2: sum[2](0) + fact[2](1) + carry(0) = 1 → 留 1 进位 0
sum = [3, 5, 1] → 翻转输出 → 153 ✅
💡 位数不同怎么办？ 和之前高精度加法一样，短的那个超出部分当 0 处理。先把 sum 扩展到和 fact 一样长（补零），再逐位相加。

⚠️ 容易踩的坑

🕳️
坑1：乘法进位没处理完
大数的每一位乘以 k 后，可能产生多位进位。比如 fact[i] × 50 最大可以到 9 × 50 = 450，进位可以是两位数（45）！
解决：乘法循环结束后，用 while (carry > 0) 把剩余的进位全部写入。
🕳️
坑2：加法时 sum 位数不够
当 fact 的位数比 sum 多时（比如 fact 是 3 位，sum 是 2 位），sum 的高位要补零参与计算。
解决：取 max(sum长度, fact长度) 来遍历，超出范围的位当 0 处理。
🕳️
坑3：输出方向搞反
数组是低位在前存的，但输出要高位在前。
解决：输出时从数组末尾往前输出（或者先翻转再输出）。

📘 C++ 魔法秘籍 (知识点)

  • 📦 用 vector<int> 存大数： 动态数组，低位在前，可以随时 push_back() 添加高位。
  • ✖️ 高精度 × 小整数： 单层循环，每一位 × k + carry，处理进位。比高精度 × 高精度简单很多！
  • ➕ 高精度 + 高精度： 就是之前学过的逐位相加、满十进一。
  • 🔁 递推思想： k! = (k-1)! × k，不需要每次从头算阶乘。

💻 C++ 终极法术 (代码详解)

#include <bits/stdc++.h>
using namespace std;

// ✖️ 高精度大数 × 普通整数
void bigMul(vector<int> &a, int k) {
    int carry = 0;
    for (int i = 0; i < a.size(); i++) {
        int temp = a[i] * k + carry;
        a[i] = temp % 10;      // 当前位留个位
        carry = temp / 10;     // 进位
    }
    // ⚠️ 剩余进位可能是多位数！
    while (carry > 0) {
        a.push_back(carry % 10);
        carry /= 10;
    }
}

// ➕ 高精度大数 + 高精度大数（sum += b）
void bigAdd(vector<int> &sum, vector<int> &b) {
    int carry = 0;
    int maxLen = max(sum.size(), b.size());
    // 确保 sum 的长度够用
    while (sum.size() < maxLen) sum.push_back(0);

    for (int i = 0; i < maxLen; i++) {
        int bv = (i < b.size()) ? b[i] : 0;
        int temp = sum[i] + bv + carry;
        sum[i] = temp % 10;
        carry = temp / 10;
    }
    if (carry > 0) sum.push_back(carry);
}

int main() {
    int n;
    cin >> n;

    vector<int> fact = {1};  // 当前阶乘，初始 = 1
    vector<int> sum  = {0};  // 总和，初始 = 0

    // 🏗️ 逐层攀登阶乘之塔
    for (int k = 1; k <= n; k++) {
        bigMul(fact, k);     // fact *= k → 得到 k!
        bigAdd(sum, fact);   // sum += k!
    }

    // 📣 从高位到低位输出
    for (int i = sum.size() - 1; i >= 0; i--) {
        cout << sum[i];
    }
    cout << endl;

    return 0;
}

📝 方法二：手动模拟（学习算法思想）

def big_mul(a, k):
    """高精度大数 × 小整数"""
    carry = 0
    for i in range(len(a)):
        temp = a[i] * k + carry
        a[i] = temp % 10
        carry = temp // 10
    # 处理剩余进位
    while carry > 0:
        a.append(carry % 10)
        carry //= 10

def big_add(s, b):
    """高精度加法 s += b"""
    carry = 0
    max_len = max(len(s), len(b))
    # 扩展 s 的长度
    while len(s) < max_len:
        s.append(0)
    for i in range(max_len):
        bv = b[i] if i < len(b) else 0
        temp = s[i] + bv + carry
        s[i] = temp % 10
        carry = temp // 10
    if carry > 0:
        s.append(carry)

def main():
    n = int(input())
    fact = [1]    # 当前阶乘 = 1
    total = [0]   # 总和 = 0

    for k in range(1, n + 1):
        big_mul(fact, k)       # fact *= k
        big_add(total, fact)   # total += fact

    # 从高位到低位输出
    print(''.join(str(x) for x in reversed(total)))

if __name__ == "__main__":
    main()

💡 技巧和重点总结 (划重点啦)

🌟
递推算阶乘： k! = (k-1)! × k。只需要维护一个"当前阶乘"变量，每次乘以 k 就自动得到下一个阶乘。不要每次从 1 重新算！
🌟
高精度 × 小整数 ≠ 高精度 × 高精度： 本题只需要大数 × 小数（单层循环），比高精度乘法简单得多！核心是 temp = a[i] * k + carry。
🌟
进位可能是多位数： 乘以 k（最大 50）时，carry 可能大于 9（比如 9 × 50 = 450，carry = 45）。循环结束后要用 while (carry > 0) 把所有进位都写入！
🌟
两种高精度组合使用： 本题综合了"高精度 × 小整数"和"高精度 + 高精度"两个操作。这是高精度问题的经典组合模式，掌握后可以应对很多变形题！
🌟
低位在前存储： 数组 [0] 放个位，这样从头遍历就是从低位到高位，计算时最方便。输出时从后往前输出即可。
