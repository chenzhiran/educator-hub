📜 任务清单 (题目描述)

孔明想要刻出一个大小为 n 的"分形图腾"。它的规律是：把一个基础的小三角形，按规律拼成更大的三角形，如此反复。

刻画要求：

  • 只使用字符 /、\、_ 和空格组成图案。
  • 一个大小为 n 的图腾，它的高度是 2^n 行，宽度是 2^(n+1) 列。
📥 魔法输入阵：
(刻画大小 n=2 的图腾)
2
📤 奇迹输出阵：
(输出由 3 个小积木拼成的雪峰)
   /\
  /__\
 /\  /\
/__\/__\

🧠 魔法道具箱 (核心图解)

绘制复杂的字符画，最好的办法不是逐行输出，而是"先铺好一张大画布，然后在指定位置盖章"。

👇 基础积木 (n=1, 高度 s=2, 宽度 4) 👇
/\ /__\
👇 分形进化 (n=2, 由 3 个基础积木拼成) 👇
/\ /__\ /\ /\ /__\/__\
👇 再进化 (n=3, 由 3 个 n=2 图腾拼成) 👇
/\ /__\ /\ /\ /__\/__\ /\ /\ /__\ /__\ /\ /\ /\ /\ /__\/__\/__\/__\
🔑 拼合规律：无论多大的图腾，都由 3 个 小一半的图腾拼成！
⛰️ 顶部 + ⛰️ 左下 + ⛰️ 右下
🎯 两种解法任你选！

🌀 解法一：递归（自顶向下拆分）

递归的思路是："画一个大雪峰" → 分解为 "画3个小雪峰"，直到最小积木为止。

函数 draw(r, c, s) 的意思是：在左上角坐标为 (r, c) 的地方，画一个高度为 s 的大雪峰！

如果大雪峰左上角是 (r, c)，高度是 s，那么它的一半高度 t = s/2：
⛰️ 顶部积木： 画在 (r, c + t)
⛰️ 左下积木： 画在 (r + t, c)
⛰️ 右下积木： 画在 (r + t, c + s)

✨ 递归的两个核心条件：

  1. 停止条件 (Base Case)： 当雪峰的高度缩小到 s == 2 时，不能再拆了！这时候直接在画布上把 /\ 和 /__\ 这个固定形状"画"上去。
  2. 拆分动作 (Recursive Step)： 如果 s > 2，就把任务分成 3 份，分别召唤 3 个尺寸减半的小雪峰。

📘 C++ 递归魔法秘籍

  • ⚡ 位运算算乘方： 1 << n 就是 2 的 n 次方，这比调用 pow(2, n) 更快，且直接返回整数类型。
  • 🎨 字符画大排版： vector<string> grid(h, string(w, ' ')) 这句魔法瞬间创建了一块满是空格的大画布！
  • ✂️ 去除行末尾迹： find_last_not_of(' ') 可以精准找到这一行最后一个"非空格"字符的位置。配合 substr 就能干净利落地切掉右边多余的空格。

💻 C++ 递归法术 (代码详解)

#include <iostream>
#include <vector>
#include <string>
using namespace std;

// 🎨 魔法画笔：在(r,c)点画一个高度为s的雪峰
void draw(int r, int c, int s, vector<string>& grid) {
    if (s == 2) {
        // 🛑 遇到最小积木啦！直接一笔一划写进画布
        grid[r][c+1] = '/';
        grid[r][c+2] = '\\';
        grid[r+1][c] = '/';
        grid[r+1][c+1] = '_';
        grid[r+1][c+2] = '_';
        grid[r+1][c+3] = '\\';
        return;
    }
    
    int t = s / 2; // t 是一半的高度
    
    // 🌀 施展递归分身术：召唤3个小一点的雪峰
    draw(r, c + t, t, grid);      // ⛰️ 顶部
    draw(r + t, c, t, grid);      // ⛰️ 左下
    draw(r + t, c + s, t, grid);  // ⛰️ 右下
}

int main() {
    int n;
    cin >> n;
    
    int h = 1 << n;       // 高度 = 2^n
    int w = 1 << (n + 1); // 宽度 = 2^(n+1)
    
    // 铺设一张装满空格的巨大画布
    vector<string> grid(h, string(w, ' '));
    
    // 挥动魔法画笔，从顶点 (0,0) 开始画
    draw(0, 0, h, grid);
    
    // 🖨️ 打印出美丽的图腾
    for (int i = 0; i < h; ++i) {
        int pos = grid[i].find_last_not_of(' ');
        if (pos != string::npos) {
            cout << grid[i].substr(0, pos + 1) << endl;
        } else {
            cout << endl; 
        }
    }
    return 0;
}

🐍 Python 递归魔法秘籍

  • 📐 二维列表生成术： [[' '] * w for _ in range(h)] 是 Python 生成独立二维数组的标准咒语！千万别写成 [[' '] * w] * h！
  • ✂️ 超级修剪工具 rstrip()： 自动把右边所有的空白字符"咔嚓"剪干净，优雅至极！
  • 🧩 转义字符的秘密： 字符串里想打印一个真正的 \，必须连写两个 \\。

💻 Python 递归法术 (代码详解)

import sys
sys.setrecursionlimit(100000)

# 🎨 魔法画笔：在(r,c)点画一个高度为s的雪峰
def draw(r, c, s, grid):
    if s == 2:
        # 🛑 遇到最小积木啦！直接写进画布
        grid[r][c+1] = '/'
        grid[r][c+2] = '\\'
        grid[r+1][c] = '/'
        grid[r+1][c+1] = '_'
        grid[r+1][c+2] = '_'
        grid[r+1][c+3] = '\\'
        return
        
    t = s // 2  # t 是一半的高度
    
    # 🌀 施展递归分身术：召唤3个小一点的雪峰
    draw(r, c + t, t, grid)      # ⛰️ 顶部
    draw(r + t, c, t, grid)      # ⛰️ 左下
    draw(r + t, c + s, t, grid)  # ⛰️ 右下

def main():
    n = int(input())
    
    h = 1 << n         # 高度 = 2^n
    w = 1 << (n + 1)   # 宽度 = 2^(n+1)
    
    # 铺设一张装满空格的巨大画布
    grid = [[' '] * w for _ in range(h)]
    
    draw(0, 0, h, grid)
    
    # 🖨️ 打印输出
    for row in grid:
        print(''.join(row).rstrip())

if __name__ == "__main__":
    main()

🧱 解法二：递推（自底向上拼合）

递推的思路和递归正好相反：先画最小的积木，然后一层层复制拼大！

就像搭积木一样：先做好一块，然后复印3份、按位置拼起来，变成更大的一块，再复印3份…… 一直到目标大小！

🔧 递推的核心思想：

第 1 步：在画布上画出最基础的小三角形 /\ 和 /__\。

第 2 步起：每一轮，当前的图案已经占据了画布上半部分。我们把整个上半部分复制两份，分别粘贴到左下和右下的位置！

递推示例：从 n=1 扩展到 n=2
已有 n=1（上半部分）
/\ /__\
→
复制到左下 + 右下
/\ /__\ /\ /\ /__\/__\
💡 复制规则：上半部分（h 行）的每一行，整体复制到下半部分的两个位置：
📋 左下：同一列偏移 → 行 +h，列不变
📋 右下：向右偏移 → 行 +h，列 +当前宽度的一半

📐 递推的坐标公式：

每一轮递推，当前图案的高度为 h（初始 h=2）：
对于上半部分第 i 行、第 j 列的非空字符 grid[i][j]：
📋 复制到 左下：grid[i + h][j - h/2] （向左偏移 h/2）
📋 复制到 右下：grid[i + h][j + h/2] （向右偏移 h/2）
然后 h 翻倍，进入下一轮！

📘 C++ 递推魔法秘籍

  • 🧱 自底向上构建： 从最小的积木开始，每轮把已有图案复制到两个新位置，不需要递归调用，用 for 循环就能搞定！
  • 📋 复制技巧： 遍历上半部分所有非空格字符，把它们复制到左下和右下。注意列的偏移量！
  • 🚀 无需递归栈： 递推法不使用函数递归，因此不会有栈溢出的风险，特别适合 n 较大的情况。

💻 C++ 递推法术 (代码详解)

#include <iostream>
#include <vector>
#include <string>
using namespace std;

int main() {
    int n;
    cin >> n;
    
    int H = 1 << n;       // 总高度 = 2^n
    int W = 1 << (n + 1); // 总宽度 = 2^(n+1)
    
    // 铺设一张装满空格的巨大画布
    vector<string> grid(H, string(W, ' '));
    
    // 🧱 第1步：在画布顶部画出最小的积木
    // 最小积木的宽度=4，画在顶部居中位置
    // 左上角坐标 (0, H-2) （因为总宽2*H，积木宽4，居中于上半部分）
    int startCol = H - 2;  // 最小积木的起始列
    grid[0][startCol + 1] = '/';
    grid[0][startCol + 2] = '\\';
    grid[1][startCol]     = '/';
    grid[1][startCol + 1] = '_';
    grid[1][startCol + 2] = '_';
    grid[1][startCol + 3] = '\\';
    
    // 🧱 第2步起：逐层递推，每轮把上半部分复制到左下和右下
    int h = 2;  // 当前图案的高度，从2开始
    for (int level = 1; level < n; level++) {
        // 遍历上半部分的每一个字符
        for (int i = 0; i < h; i++) {
            for (int j = 0; j < W; j++) {
                if (grid[i][j] != ' ') {
                    // 📋 复制到左下：行+h，列向左偏移h/2
                    int newCol1 = j - h / 2;
                    if (newCol1 >= 0 && newCol1 < W)
                        grid[i + h][newCol1] = grid[i][j];
                    
                    // 📋 复制到右下：行+h，列向右偏移h/2
                    int newCol2 = j + h / 2;
                    if (newCol2 >= 0 && newCol2 < W)
                        grid[i + h][newCol2] = grid[i][j];
                }
            }
        }
        h *= 2;  // 图案高度翻倍，进入下一轮！
    }
    
    // 🖨️ 打印出美丽的图腾
    for (int i = 0; i < H; ++i) {
        int pos = grid[i].find_last_not_of(' ');
        if (pos != string::npos) {
            cout << grid[i].substr(0, pos + 1) << endl;
        } else {
            cout << endl;
        }
    }
    return 0;
}

🐍 Python 递推魔法秘籍

  • 🧱 自底向上构建： 从最小的积木开始，用 for 循环逐层复制拼大，无需递归！
  • 📋 复制要检查边界： 列偏移后要确保不越界（0 ≤ j < W）。
  • 🚀 无栈溢出风险： 递推法不使用函数递归，不需要设置 sys.setrecursionlimit。

💻 Python 递推法术 (代码详解)

def main():
    n = int(input())
    
    H = 1 << n         # 总高度 = 2^n
    W = 1 << (n + 1)   # 总宽度 = 2^(n+1)
    
    # 铺设一张装满空格的巨大画布
    grid = [[' '] * W for _ in range(H)]
    
    # 🧱 第1步：在画布顶部画出最小的积木
    sc = H - 2  # 最小积木的起始列
    grid[0][sc + 1] = '/'
    grid[0][sc + 2] = '\\'
    grid[1][sc]     = '/'
    grid[1][sc + 1] = '_'
    grid[1][sc + 2] = '_'
    grid[1][sc + 3] = '\\'
    
    # 🧱 第2步起：逐层递推
    h = 2  # 当前图案的高度
    for level in range(1, n):
        # 遍历上半部分的每一个字符
        for i in range(h):
            for j in range(W):
                if grid[i][j] != ' ':
                    # 📋 复制到左下
                    c1 = j - h // 2
                    if 0 <= c1 < W:
                        grid[i + h][c1] = grid[i][j]
                    # 📋 复制到右下
                    c2 = j + h // 2
                    if 0 <= c2 < W:
                        grid[i + h][c2] = grid[i][j]
        h *= 2  # 高度翻倍
    
    # 🖨️ 打印输出
    for row in grid:
        print(''.join(row).rstrip())

if __name__ == "__main__":
    main()

⚖️ 两种解法对比

对比项 🌀 递归（自顶向下） 🧱 递推（自底向上）
思路方向 从大到小拆分 从小到大拼合
核心操作 函数自己调用自己 for 循环逐层复制
画基础积木 在递归最底层画 在最开始画
坐标计算 相对坐标（父传给子） 绝对坐标（偏移复制）

💡 技巧和重点总结 (划重点啦)

  • 🌟 画布思维 (Canvas Pattern)： 绝大多数二维字符图案题，最忌讳用一重重的 for 循环一行行硬拼。学会先开一个巨大的二维数组当"画布"，然后用 绝对坐标 去涂色，这是一种降维打击的思维！
  • 🌟 找准基准点： 坐标转换是这题的难点。递归法统一把 左上角 定为 (r, c)；递推法则用偏移量来确定复制的目标位置。画个草图就清晰了！
  • 🌟 分形与递归/递推的血缘关系： 分形（Fractal）的本质就是"局部和整体相似"。递归是从大往小拆，递推是从小往大拼，殊途同归！
  • 🌟 递推的复制技巧： 递推法的关键洞察是——上半部分的每个字符，复制两份到下半部分的对称位置。列向左偏移 h/2 是左下，向右偏移 h/2 是右下。
