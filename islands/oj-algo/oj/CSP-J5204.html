📋 方向规则大对照表

关键发现：朝向和指令方向"同"则顺时针（索引减），"异"则逆时针（索引加）

🧍 当前朝向 (dir) 📋 指令方向 (a) 🔄 实际移动 📐 索引变化 (delta)
朝内 (0) 左 (0) 顺时针 ↻ −s（索引减小）
朝内 (0) 右 (1) 逆时针 ↺ +s（索引增大）
朝外 (1) 左 (0) 逆时针 ↺ +s（索引增大）
朝外 (1) 右 (1) 顺时针 ↻ −s（索引减小）
💡 规律总结： 当 dir == a（朝向和指令方向相同）→ 顺时针 → delta = -s；当 dir ≠ a（不同）→ 逆时针 → delta = +s。

🔁 环形取模：圆圈上的数学魔法

小人围成一圈，编号 0 ~ n-1。当我们走过头时（走出了 0 或 n-1），就要"绕回来"！这就是取模运算的用武之地。

... 5
6
0
1
2 ...
← 从编号 6 再往后走一步，就回到了编号 0 →
新位置 = (cur + delta + n) % n
为什么要 +n？ 因为 delta 可能是负数（顺时针），加上 n 保证取模前是正数！
例子（n=7）：
(0 + (-3) + 7) % 7
= (4) % 7 = 4 ✅
例子（n=7）：
(5 + 3 + 7) % 7
= (15) % 7 = 1 ✅

🌈 样例 2 简析：10个小人，10条指令

样例2有10个小人和10条指令，计算过程完全相同，只是步数更多。按照同样的规则一步步执行即可，最终到达编号7的小人 y。

💡 提示： 不管有多少个小人、多少条指令，我们的算法都是一样的——每条指令只需要做一次判断和一次取模运算，时间复杂度 O(m)，非常高效！

⚠️ 容易踩的坑

🕳️
坑1：负数取模
当 delta 为负数时，直接取模在 C++ 中可能得到负数！比如 (-3) % 7 在 C++ 中可能是 -3 而不是 4。
解决：用 (cur + delta + n) % n，先加一个 n 保证是正数。Python 中负数取模结果自动是正数，不需要额外处理。
🕳️
坑2：搞混朝向方向规则
朝内向左 = 顺时针（索引减），朝外向左 = 逆时针（索引加）。最容易出错的地方！
解决：记住规律 —— dir == a 时顺时针（delta = -s），dir ≠ a 时逆时针（delta = +s）。
🕳️
坑3：搞混 "当前小人" 和 "指令小人"
每条指令中判断方向要看的是当前所在位置小人的朝向，不是别的小人。
解决：每次都用 persons[cur] 的朝向来判断。

📘 C++ 魔法秘籍 (知识点)

  • 📦 结构化存储 pair<int, string>： 用 vector<pair<int, string>> 存储每个小人的朝向和职业，方便同时访问两个属性。
  • 🔁 环形取模： (cur + delta + n) % n 是处理环形数组的标准写法，加 n 避免负数取模的问题。
  • 📖 输入技巧： cin >> dir >> name 可以同时读取一个整数和一个字符串（用空格分隔）。

💻 C++ 终极法术 (代码详解)

#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;  // 📥 小人个数 和 指令条数

    // 📥 存储每个小人的信息
    vector<pair<int, string>> persons(n);
    for (int i = 0; i < n; i++) {
        cin >> persons[i].first >> persons[i].second;
        // first = 朝向(0朝内/1朝外)
        // second = 职业名
    }

    int cur = 0;  // 🧭 当前位置，从第 0 个小人开始

    // 🔄 逐条执行指令
    for (int i = 0; i < m; i++) {
        int a, s;
        cin >> a >> s;  // a=方向(0左/1右), s=步数

        int dir = persons[cur].first;  // 当前小人的朝向
        int delta;

        // 🎯 根据朝向和指令判断实际移动方向
        if (dir == a) {
            // 朝向和指令方向相同 → 顺时针 → 索引减
            delta = -s;
        } else {
            // 朝向和指令方向不同 → 逆时针 → 索引加
            delta = s;
        }

        // 🔁 环形取模，+n 防止负数
        cur = (cur + delta + n) % n;
    }

    // 📣 输出最终到达的小人的职业
    cout << persons[cur].second << endl;

    return 0;
}

🐍 Python 魔法秘籍 (知识点)

  • 📦 元组列表存储： 用 persons = [(dir, name), ...] 存储每个小人的信息，Python 的元组解包让访问数据非常优雅。
  • 🔁 负数取模的福利： Python 中 (-3) % 7 = 4，自动得到正数结果！不需要额外加 n。但写 (cur + delta) % n 就够了。
  • 📖 输入分割： input().split() 可以把一行按空格分成列表，然后分别取出整数和字符串部分。

💻 Python 终极法术 (代码详解)

def main():
    n, m = map(int, input().split())

    # 📥 存储每个小人的信息 (朝向, 职业)
    persons = []
    for _ in range(n):
        parts = input().split()
        d = int(parts[0])     # 朝向: 0朝内, 1朝外
        name = parts[1]       # 职业名
        persons.append((d, name))

    cur = 0  # 🧭 当前位置，从第 0 个小人开始

    # 🔄 逐条执行指令
    for _ in range(m):
        a, s = map(int, input().split())
        # a = 方向(0左/1右), s = 步数

        d = persons[cur][0]  # 当前小人的朝向

        # 🎯 根据朝向和指令判断实际移动方向
        if d == a:
            # 朝向和指令方向相同 → 顺时针 → 索引减
            delta = -s
        else:
            # 朝向和指令方向不同 → 逆时针 → 索引加
            delta = s

        # 🔁 环形取模（Python 负数取模自动正确）
        cur = (cur + delta) % n

    # 📣 输出最终到达的小人的职业
    print(persons[cur][1])

if __name__ == "__main__":
    main()

💡 技巧和重点总结 (划重点啦)

🌟
环形数组用取模： 当小人围成一圈时，用 (cur + delta + n) % n 来实现"走到头就绕回来"的效果。这是处理环形结构的标准公式，背下来！
🌟
朝向规律一句话记忆： dir == a → 顺时针(delta=-s)；dir ≠ a → 逆时针(delta=+s)。记住这个规律比死记四种情况简单多了！
🌟
注意"逆时针编号"： 题目说小人按逆时针顺序输入。逆时针 = 编号增大方向，顺时针 = 编号减小方向。这是理解 delta 正负号的基础。
🌟
C++ 负数取模要当心： C++ 中 (-3) % 7 可能得到 -3。一定要用 + n 来保证结果是正数。Python 没有这个问题。
