⚡ 核心算法：二分答案 + 贪心检查

💡 关键思想：反转问题！

原问题：移走 ≤ M 块石头后，最短跳跃距离最大是多少？

反转成：
猜一个答案 x → 问：如果要让每一跳都 ≥ x，最少需要移走几块石头？
• 如果需要移走的 ≤ M → x 可行，可以尝试更大的 x
• 如果需要移走的 > M → x 不可行，必须减小 x

这就是"二分答案"的套路！答案具有单调性：
x 越小 → 越容易满足（移走更少石头）
x 越大 → 越难满足（需移走更多石头）

📊 答案的单调性图示

猜 x
x=1 ✅
x=2 ✅
x=3 ❌
x=4 ❌
... ❌
✅ 可行区域 和 ❌ 不可行区域 之间有一条分界线
我们要找的就是最右边的 ✅ → 用二分搜索！
✨ 二分答案模板 ✨
lo = 0, hi = L
while lo < hi:
  mid = (lo + hi + 1) / 2
  if check(mid): lo = mid
  else: hi = mid - 1
答案 = lo
注意：因为我们要找最大的可行值，用的是"左闭右闭、取上中位数"的模板

🔍 check(x) 贪心检查怎么做？

思路：从起点出发，贪心地保留/移走石头

维护一个变量 last = 上一个保留的位置（初始为 0 = 起点）

遍历每块石头的位置 d[i]：

  • 如果 d[i] - last < x（距离上一个保留点太近）→ 移走它！removed++
  • 如果 d[i] - last ≥ x（够远）→ 保留它！更新 last = d[i]

遍历完后检查终点：如果 L - last < x，最后一段也不够 → removed++

最终：removed ≤ M → 可行！

⚠️ 细节：终点的处理

🚨 别忘了检查最后一段！

遍历完所有石头后，还要检查最后一个保留的石头到终点 L 的距离。

如果 L - last < x，说明最后一跳太短了！
解决方法：把 last 位置的石头也移走（removed++），让更前面的石头直接跳到终点。

举例：x=5, 石头=[2, 8], L=10, M=1
• last=0, 石头(2): 2 < 5 → 移走，removed=1
• last=0, 石头(8): 8 ≥ 5 → 保留，last=8
• 检查终点：10-8=2 < 5 → removed++ = 2
• 2 > M=1 → ❌ 不可行

📘 C++ 知识点

  • 🔍 二分答案模板： while(lo < hi) + 取上中位数 mid = (lo+hi+1)/2，寻找最大的可行值。
  • 🟢 贪心 check 函数： 从左到右扫描，太近就移走，够远就保留。O(N) 搞定。
  • 📦 数据类型： L ≤ 10⁹ 用 int 即可（不会溢出），但用 long long 也无妨。
  • ⚡ 快读： 数据量不大（N ≤ 5×10⁴），cin 足够。更大数据可用 scanf。

💻 C++ 代码

#include <iostream>
using namespace std;

int L, N, M;
int d[50005];  // 石头位置

// 🟢 贪心检查：最短跳跃距离至少为 x，需要移走多少块？
bool check(int x) {
    int removed = 0;   // 移走的石头数
    int last = 0;      // 上一个保留点的位置（起点=0）

    for (int i = 0; i < N; i++) {
        if (d[i] - last < x) {
            // 📏 太近了，移走这块石头
            removed++;
        } else {
            // ✅ 够远，保留它
            last = d[i];
        }
    }

    // 🏁 检查最后一段（last 到终点 L）
    if (L - last < x) removed++;

    return removed <= M;
}

int main() {
    cin >> L >> N >> M;
    for (int i = 0; i < N; i++)
        cin >> d[i];

    // 🔍 二分答案：在 [0, L] 中找最大的可行 x
    int lo = 0, hi = L;
    while (lo < hi) {
        int mid = (lo + hi + 1) / 2;  // 取上中位数
        if (check(mid)) {
            lo = mid;       // ✅ 可行，尝试更大
        } else {
            hi = mid - 1;   // ❌ 不可行，缩小上界
        }
    }

    cout << lo << endl;
    return 0;
}

🐍 Python 知识点

  • 🔍 二分答案模板： 和 C++ 逻辑完全相同。while lo < hi + 上中位数。
  • 🟢 贪心 check 函数： 一次遍历，O(N)。
  • ⚡ sys.stdin 加速： N 最大 5万，建议用 sys.stdin 读入。
  • 🐍 整数除法： // 是整除。Python 不用担心整数溢出。

💻 Python 代码

import sys
input = sys.stdin.readline

def check(x):
    """贪心检查：最短跳跃距离 >= x，需移走多少块？"""
    removed = 0
    last = 0  # 上一个保留点

    for i in range(N):
        if d[i] - last < x:
            removed += 1   # 太近，移走
        else:
            last = d[i]     # 够远，保留

    # 🏁 检查最后一段
    if L - last < x:
        removed += 1

    return removed <= M

# 📥 读入
L, N, M = map(int, input().split())
d = [int(input()) for _ in range(N)]

# 🔍 二分答案
lo, hi = 0, L
while lo < hi:
    mid = (lo + hi + 1) // 2
    if check(mid):
        lo = mid        # ✅ 可行，尝试更大
    else:
        hi = mid - 1    # ❌ 不可行

print(lo)

💡 什么时候用"二分答案"？

当你发现：
1️⃣ 直接求答案很难，但验证一个答案是否可行很容易（贪心/模拟）
2️⃣ 答案有单调性：越小越容易可行（或越大越容易）

经典题型：最大化最小值、最小化最大值 → 都可以二分答案！

✅ 样例验证

样例 1：L=10, N=3, M=1, d=[2,6,7]
check(2)：移走 7（1块）≤ 1 → ✅
check(3)：移走 2,7（2块）> 1 → ❌
答案 = 2 ✅
样例 2：L=25, N=5, M=2, d=[2,11,14,17,21]
check(4)：移走 2,14（2块）≤ 2 → ✅
check(5)：移走 2,14,21（3块）> 2 → ❌
答案 = 4 ✅
样例 3：L=50, N=8, M=3, d=[4,10,17,24,28,33,40,45]
check(7)：移走 4,28,45（3块）≤ 3 → ✅
check(8)：移走 4,28,33,45（4块）> 3 → ❌
答案 = 7 ✅
边界：N=0（没有石头）
没有中间石头，只能跳 L → 答案 = L ✅
（check 函数不进入循环，removed=0 ≤ M → lo 会一直上升到 L）
边界：M=N（全部移走）
所有石头都可以移走 → 只需从 0 跳到 L → 答案 = L ✅
边界：M=0（不能移走）
必须保留所有石头 → 答案 = 相邻石头间的最短距离 ✅

经典同类题：
  • 🐄 Aggressive Cows：N 个牛棚放 C 头牛，最大化最近两头牛的距离
  • 🍰 分蛋糕：切 N 段绳子为 K 段等长，最大化每段长度
  • 📦 关押罪犯：最小化最大冲突（上一题！也可二分答案解）

这些题的核心套路都是一样的：猜答案 → 验证 → 二分缩小范围。

💡 技巧和重点总结 (划重点啦)

  • 🎯 二分答案思想： 不直接求"最优解是多少"，而是猜一个答案 x，检查"x 是否可行"。利用答案的单调性，用二分搜索找到最优的 x。这是解决"最大化最小值"类问题的神器！
  • 🟢 贪心 check 函数： 从左到右扫描石头，太近（< x）就移走，够远（≥ x）就保留。最后别忘了检查终点！时间复杂度 O(N)，简单高效。
  • 📏 二分范围： lo = 0（最短跳跃可以是 0），hi = L（最远就是一步到终点）。二分轮数 = log₂(L) ≈ 30 次。
  • ⚡ 总体复杂度： O(N × log L)。当 N = 50000, L = 10⁹ 时，约 50000 × 30 = 150 万次运算，毫秒级搞定！
  • 🛡️ 上中位数防死循环： 找最大可行值时，mid 要取 (lo+hi+1)/2（上中位数），否则当 lo+1==hi 时会死循环。这是二分答案的经典坑！
