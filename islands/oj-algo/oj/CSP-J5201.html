🌈 样例 3：史诗级拉锯战

分析： 第一行有 99 个 W（第二行紧接着还有 2 个 W），第二行后面有大量 L。

🗺️ 比赛大局势图

📊 最终输出：

💡 样例 3 中 2:11 是怎么来的？
第 10 局开始时，安雅从上一局清零后，先得了 2 分（来自第二行开头的 2 个 W）。然后对手连续得 11 分（来自 L）。此时比分 2:11，满足 11 ≥ 11 且 |2-11| = 9 ≥ 2，这局结束！

🔥 特殊情况：10:10 平局加时赛

当双方打到 10:10 时，情况变得刺激起来！让我们看看会发生什么：

⚡ 加时赛演示
比分 10:10 → 分差 = 0 ❌ 继续！
⬇️ 安雅得 1 分
比分 11:10 → 分差 = 1 ❌ 继续！
⬇️ 对手追 1 分
比分 11:11 → 分差 = 0 ❌ 继续！
⬇️ 安雅连得 2 分
比分 13:11 → 分差 = 2 ✅ 安雅赢！
🎯 一句话总结： 不管分数多高，只要分差不到 2，比赛就不会结束！我们的条件判断会自动处理这种情况，因为只有 abs(w - l) >= 2 才会触发输出。

📘 C++ 魔法秘籍 (知识点)

  • 📖 逐字符读入 cin >> temp： cin >> char 会自动跳过空格和换行符，只抓取有用的字符，这让跨行输入的处理变得非常轻松！
  • 📦 字符数组 char s[100000]： 我们先把 E 之前的所有记录存进一个大口袋里，然后统一处理，思路更清晰。
  • 📐 绝对值函数 abs()： 用来计算分差，不用管谁比谁大，直接取绝对值就行。需要 #include <cstdlib> 或 <cmath>（实际上 iostream 一般已经间接包含了）。

💻 C++ 终极法术 (代码详解)

#include <bits/stdc++.h>
using namespace std;

// 准备一个大口袋装所有的比赛记录
char s[100000];

int main() {
    char temp;
    int idx = 0;

    // 📥 步骤一：读入数据直到遇到终末宝石 'E'
    // cin >> temp 会自动跳过空格和换行，完美处理多行输入！
    while (cin >> temp && temp != 'E') {
        if (temp == 'W' || temp == 'L') {
            s[idx++] = temp;  // 把有效宝石收入口袋
        }
    }

    int w = 0, l = 0;  // 安雅得分 和 对手得分

    // ✍️ 步骤二：遍历口袋里的每一颗宝石
    for (int i = 0; i < idx; i++) {
        if (s[i] == 'W')
            w++;          // 胜利宝石 → 安雅加1分
        else
            l++;          // 失败宝石 → 对手加1分

        // 🏆 步骤三：检查这局结束了吗？
        // 条件：有人 ≥ 11分 且 分差 ≥ 2
        if ((w >= 11 || l >= 11) && abs(w - l) >= 2) {
            cout << w << ":" << l << endl;  // 报幕！
            w = 0;
            l = 0;   // 记分牌清零，下一局开始
        }
    }

    // 📣 步骤四：处理最后没打完的一局
    if (w != 0 || l != 0) {
        cout << w << ":" << l << endl;
    }

    return 0;
}

🐍 Python 魔法秘籍 (知识点)

  • 📖 多行读入 sys.stdin： Python 中 sys.stdin 可以逐行读取所有输入，配合 for line in sys.stdin 循环就能处理任意行数的输入。
  • 📦 列表 records.append(ch)： Python 的列表就像一个可以自动变大的魔法口袋，往里面扔多少宝石都不会满！
  • 📐 绝对值 abs()： Python 内置函数，直接用，不需要导入任何库。
  • ♾️ 自动防溢出： Python 的整数可以无限大，完全不用担心数字太大的问题！

💻 Python 终极法术 (代码详解)

import sys

def main():
    # 📥 步骤一：像吸尘器一样读入所有数据
    records = []  # 魔法口袋，存放有效宝石
    found_end = False

    for line in sys.stdin:
        for ch in line.strip():
            if ch == 'E':   # 看到终末宝石就停止！
                found_end = True
                break
            if ch == 'W' or ch == 'L':
                records.append(ch)  # 收集有效宝石
        if found_end:
            break

    w = 0  # 安雅得分
    l = 0  # 对手得分

    # ✍️ 步骤二：遍历每一颗宝石，逐球记分
    for ch in records:
        if ch == 'W':
            w += 1    # 胜利宝石 → 安雅加1分
        else:
            l += 1    # 失败宝石 → 对手加1分

        # 🏆 步骤三：检查获胜条件
        # 有人 ≥ 11分 且 分差 ≥ 2
        if (w >= 11 or l >= 11) and abs(w - l) >= 2:
            print(f"{w}:{l}")  # 报幕！
            w, l = 0, 0         # 清零，下一局

    # 📣 步骤四：最后没打完的也要报幕哦！
    if w != 0 or l != 0:
        print(f"{w}:{l}")

if __name__ == "__main__":
    main()

💡 技巧和重点总结 (划重点啦)

🌟
模拟是核心： 这道题不需要高深的算法，就是一步步按照规则模拟比赛过程。关键是理解清楚规则，然后逐字符处理。
🌟
两个条件缺一不可： 获胜判定是 (w≥11 || l≥11) && abs(w-l)≥2。忘了分差条件？10:10 后会一直不结束！忘了 11 分条件？5:3 就结束了！
🌟
别忘了最后一局： 如果宝石序列结束时，当前比分不是 0:0（还在进行中的一局），也要把它输出来。这是很多同学容易漏掉的边界！
🌟
跨行输入不用怕： C++ 的 cin >> char 和 Python 的 sys.stdin 都能自动处理多行输入。先读完所有数据，再统一处理，思路最清晰！
