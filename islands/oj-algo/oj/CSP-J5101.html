数学表达：n % k == 0（n 除以 k 余数为 0）

⚠️ 这个方法的问题在哪？

当 n 很大时（比如 n = 109 = 10亿），循环要跑 10亿次！
计算机每秒大约能执行 108 次运算，这就需要约 10秒 ⏰ → 超时！

📘 C++ 解法一 · 知识点

  • 📦 vector动态数组： vector<int> divisors 不需要预先指定大小，可以随时 push_back() 添加元素。
  • 🔢 取余运算： n % i == 0 就是判断 n 能否被 i 整除，这是判断因数的核心操作。
  • 📏 .size() 方法： divisors.size() 返回数组中已有元素的个数。

💻 C++ 逐个检查代码

#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;

    vector<int> divisors;  // 存放所有因数

    // 🐢 从 1 到 n，逐个检查
    for (int i = 1; i <= n; i++) {
        if (n % i == 0) {
            divisors.push_back(i);  // 能整除就是因数！
        }
    }

    // 输出个数
    cout << divisors.size() << endl;

    // 输出所有因数（空格分隔）
    for (int i = 0; i < divisors.size(); i++) {
        if (i > 0) cout << " ";
        cout << divisors[i];
    }
    cout << endl;

    return 0;
}

🐍 Python 解法一 · 知识点

  • 📦 列表 append： divisors.append(i) 把新发现的因数添加到列表末尾。
  • 🔢 取余运算： n % i == 0 判断 i 是否为 n 的因数。
  • 🖨️ 打印列表： print(*divisors) 用星号解包，自动以空格分隔输出列表所有元素。

💻 Python 逐个检查代码

n = int(input())

print(len(divisors))

⚡ 解法二：√n 优化（成对发现因数）

💡 核心洞察：因数总是成对出现的！

如果 i 是 n 的因数，那么 n / i 也一定是因数！
例如 12 ÷ 3 = 4，所以 3 和 4 都是 12 的因数——它们是一对！
我们只需要检查到 √n，就能找到所有因数！

📘 C++ 解法二 · 知识点

  • 📐 平方根循环： i * i <= n 等价于 i <= √n，但避免了浮点数精度问题。用乘法比 sqrt() 更安全！
  • 🔗 成对收集： 找到因数 i 时，同时把 n / i 也收集起来。注意判断 i != n / i 防止重复。
  • 📊 排序输出： 因为大因数是"倒着"收集的，所以最后需要 sort() 排序。
  • ⚡ long long 注意： 当 n 达到 109 时，i * i 可能溢出 int 范围。用 long long 或者 (long long)i * i 确保安全。

💻 C++ √n 优化代码

#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    long long n;
    cin >> n;

    vector<long long> divisors;

    // ⚡ 只循环到 √n（用 i*i <= n 避免浮点误差）
    for (long long i = 1; i * i <= n; i++) {
        if (n % i == 0) {
            divisors.push_back(i);      // 记录小因数 i
            if (i != n / i) {
                divisors.push_back(n / i); // 记录配对的大因数
            }
        }
    }

    // 📊 排序（因为大因数不是按顺序添加的）
    sort(divisors.begin(), divisors.end());

    // 输出
    cout << divisors.size() << endl;
    for (int i = 0; i < divisors.size(); i++) {
        if (i > 0) cout << " ";
        cout << divisors[i];
    }
    cout << endl;

    return 0;
}

🐍 Python 解法二 · 知识点

  • 📐 平方根循环： while i * i <= n 或 for i in range(1, int(n**0.5) + 1)，只检查到 √n。
  • 🔗 成对收集： 找到 i 时同时记录 n // i（整除）。
  • 📊 排序： 最后用 divisors.sort() 或 sorted() 排成升序。
  • 🐍 Python 整数无上限： Python 的 int 天然支持大数，不需要担心溢出问题。

💻 Python √n 优化代码

n = int(input())

divisors = []

# ⚡ 只循环到 √n
i = 1
while i * i <= n:
    if n % i == 0:
        divisors.append(i)        # 记录小因数
        if i != n // i:
            divisors.append(n // i)  # 记录配对的大因数
    i += 1

# 📊 排序
divisors.sort()

# 输出
print(len(divisors))
print(*divisors)

🔍 解法二执行过程详解 (n = 12)

📋 循环 i 从 1 开始，直到 i×i > 12 停止：
i = 1： 1×1 = 1 ≤ 12 ✅    12%1 = 0 → 记录 1 和 12
  divisors = [1, 12]

i = 2： 2×2 = 4 ≤ 12 ✅    12%2 = 0 → 记录 2 和 6
  divisors = [1, 12, 2, 6]

i = 3： 3×3 = 9 ≤ 12 ✅    12%3 = 0 → 记录 3 和 4
  divisors = [1, 12, 2, 6, 3, 4]

i = 4： 4×4 = 16 > 12 ❌    停止循环！

排序后： [1, 2, 3, 4, 6, 12]   共 6 个 ✅

💡 技巧和重点总结 (划重点啦)

  • 🍎 因数的含义： n 能被 i 整除（n % i == 0），那 i 就是 n 的因数。理解了这一点，代码就是一个简单的循环+判断。
  • 🔗 因数配对原理： 因数总是成对出现：如果 i 是因数，那 n/i 也是。利用这个性质，只需检查到 √n 就够了！这是从 O(n) 优化到 O(√n) 的关键思想。
  • ⚠️ 完全平方数陷阱： 当 i × i = n 时（如 n=16, i=4），i 和 n/i 是同一个数，千万别重复添加！加一个 if (i != n/i) 判断即可。
  • 📊 排序别忘记： √n 优化法收集因数的顺序不是从小到大的（先收集小的，再跳着收集大的），所以最后一定要排序！
  • ⚡ i*i ≤ n 比 i ≤ sqrt(n) 更好： 用乘法判断循环条件，避免了浮点数的精度问题，是竞赛中的常用技巧。
