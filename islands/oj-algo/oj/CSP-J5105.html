📏 什么是"最小公倍数"？

🔗 GCD 和 LCM 的神奇关系

✨ 核心公式 ✨
LCM(a, b) = a × b ÷ GCD(a, b)
即：lcm = a * b / gcd
或更安全：lcm = a / gcd * b（先除后乘，防溢出）
验证样例 1： a=10, b=16, GCD=2
LCM = 10 × 16 ÷ 2 = 160 ÷ 2 = 80 ✅

验证样例 2： a=6, b=9, GCD=3
LCM = 6 × 9 ÷ 3 = 54 ÷ 3 = 18 ✅
为什么这个公式成立？

a 和 b 的乘积 = GCD × LCM × 1（但更准确地说）：
a = GCD × m，b = GCD × n，其中 m 和 n 互质（没有公因数）
LCM = GCD × m × n = a × n = b × m
a × b = GCD × m × GCD × n = GCD × (GCD × m × n) = GCD × LCM
所以 LCM = a × b ÷ GCD 🎯

🎯 两种求 GCD 的方法！

🐢 方法一：从大到小枚举

最直觉的想法：从 min(a,b) 开始往下试，找到第一个同时整除 a 和 b 的数就是 GCD。

例：GCD(10, 16)
min(10,16) = 10
试 10: 16%10=6 ❌
试 9: 10%9=1 ❌
试 8: 10%8=2 ❌
试 7: 10%7=3 ❌
试 6: 10%6=4 ❌
试 5: 16%5=1 ❌
试 4: 10%4=2 ❌
试 3: 10%3=1 ❌
试 2: 10%2=0 ✅ 且 16%2=0 ✅ → GCD = 2！
⚠️ 效率问题

最坏情况下要从 min(a,b) 一路试到 1，时间复杂度 O(min(a,b))。
当 a, b 达到 109 时，需要 109 次运算 → 超时！🐌
我们需要更快的算法……

⚡ 方法二：辗转相除法（欧几里得算法）

💡 核心原理

GCD(a, b) = GCD(b, a % b)

这个等式说：a 和 b 的最大公约数 = b 和 (a除以b的余数) 的最大公约数！
不断重复这个过程，直到余数变成 0，此时的 b 就是答案。

终止条件：当 b = 0 时，GCD(a, 0) = a。

⚡ 为什么这么快？

🐢 枚举法
O(min(a,b))
a=10⁹ → 10⁹ 次
⚡ 辗转相除
O(log(min(a,b)))
a=10⁹ → 约 30 次！🚀
💡 为什么只需要 ~30 步？

每一步取余后，数字至少减小一半！（可以证明 a % b ≤ a/2）
所以步数 ≤ 2 × log₂(max(a,b))。
当 a = 10⁹ 时，log₂(10⁹) ≈ 30，最多约 60 步。
比枚举法快了 3000 万倍！ 这就是算法的力量！💪

⚠️ LCM 计算的溢出陷阱

🚨 先除后乘，避免溢出！

公式：LCM = a * b / gcd

危险写法： a * b / gcd
当 a = b = 109 时，a × b = 1018，超过 int 范围（2×10⁹），甚至可能超过 long long（9.2×1018）！

安全写法： a / gcd * b
先除后乘！因为 a 一定能被 gcd 整除，所以 a/gcd 不会有精度问题，
且 a/gcd × b 的结果范围更小、更安全。

C++ 注意：必须用 long long！
Python 注意：Python 大整数不会溢出，但也建议先除后乘。

例：a = 10⁹, b = 10⁹, gcd = 10⁹

❌ 危险： a * b = 1018（可能溢出）/ 10⁹ = 10⁹
✅ 安全： a / gcd = 10⁹ / 10⁹ = 1, 然后 1 * 10⁹ = 10⁹ → 结果正确！

📘 C++ 知识点

  • 🔄 递归函数： gcd(a, b) 调用自己 gcd(b, a%b)，直到 b=0 返回 a。这是递归的经典应用！
  • 📦 long long 类型： a, b 最大 10⁹，乘积可达 10¹⁸，必须用 long long（64位整数）。
  • ⚡ 三目运算符： b == 0 ? a : gcd(b, a%b) 一行搞定！等价于 if-else。
  • 🛡️ 先除后乘： a / g * b 而不是 a * b / g，防止中间结果溢出。

💻 C++ 代码（辗转相除法）

#include <iostream>
using namespace std;

// ⚡ 辗转相除法求最大公约数
long long gcd(long long a, long long b) {
    if (b == 0) return a;  // 终止条件：余数为0
    return gcd(b, a % b);   // 递归：GCD(a,b) = GCD(b, a%b)
}

int main() {
    long long a, b;
    cin >> a >> b;

    long long g = gcd(a, b);           // 最大公约数
    long long l = a / g * b;            // 最小公倍数（先除后乘！）

    cout << g << endl;
    cout << l << endl;

    return 0;
}

💻 C++ 代码（非递归写法）

#include <iostream>
using namespace std;

int main() {
    long long a, b;
    cin >> a >> b;

    // ⚡ 非递归版辗转相除法
    long long x = a, y = b;
    while (y != 0) {
        long long temp = y;
        y = x % y;     // 余数
        x = temp;       // 原来的 b 变成新的 a
    }
    // 循环结束后，x 就是 GCD

    long long g = x;
    long long l = a / g * b;   // 先除后乘，防溢出

    cout << g << endl;
    cout << l << endl;

    return 0;
}

🐍 Python 知识点

  • 📦 内置 gcd： math.gcd(a, b) 直接计算最大公约数（Python 3.5+）。比自己写更快更安全。
  • 🐍 Python 大整数： Python 的整数没有大小限制，不用担心溢出！但良好习惯仍建议先除后乘。
  • ➗ 整除运算： // 是整除运算符，结果为整数。/ 会得到浮点数，千万别搞混！
  • 🔄 手写递归： 也可以自己实现辗转相除法，理解算法原理。

💻 Python 代码（手写辗转相除法）

# ⚡ 手写辗转相除法（理解原理）
def gcd(a, b):
    while b != 0:
        a, b = b, a % b   # Python 的交换赋值，一行搞定！
    return a

a, b = map(int, input().split())

g = gcd(a, b)
l = a // g * b

print(g)
print(l)

📋 GCD / LCM 性质速查表

性质 GCD（最大公约数） LCM（最小公倍数）
含义 能同时整除 a, b 的最大数 同时是 a, b 倍数的最小数
范围 1 ≤ GCD ≤ min(a,b) max(a,b) ≤ LCM ≤ a×b
互质时 GCD = 1 LCM = a × b
a=b 时 GCD = a LCM = a
a|b 时 GCD = a（较小的那个） LCM = b（较大的那个）
关系 GCD × LCM = a × b

💡 技巧和重点总结 (划重点啦)

  • 🔑 辗转相除法（欧几里得算法）： GCD(a, b) = GCD(b, a % b)，当 b = 0 时返回 a。这是求 GCD 的标准方法，只需 O(log n) 步，即使 a, b 高达 10⁹ 也秒出结果！
  • 🔗 GCD 与 LCM 的关系： LCM = a / GCD * b。记住这个公式，用 GCD 一步推出 LCM！千万不要两个都暴力算。
  • 🛡️ 先除后乘防溢出： C++ 中 a × b 可能超过 long long 范围。写 a / g * b 而不是 a * b / g，先除再乘，确保中间结果不溢出！
  • 📦 类型要用 long long： a, b 最大 10⁹，LCM 最大可达 10¹⁸，int（2×10⁹）装不下，必须用 long long！Python 无此顾虑。
