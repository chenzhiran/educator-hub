📜 任务清单 (题目描述)

N 个能量箱排成一列，要分成恰好 M 段连续的补给卷。

目标：让所有段中能量和最大的那一段，尽可能小！

📐 输入输出格式：
• 输入：第1行 N, M；第2行 N 个非负整数 Ai
• 输出：一个整数——各段和最大值的最小值
• 数据范围：1 ≤ N ≤ 105，M ≤ N，Ai < 108，答案 ≤ 109

暴力枚举所有分法可行吗？

N 个箱子分 M 段 → 选 M-1 个分割点 → C(N-1, M-1) 种方案。
当 N=100000 时，这个数字大到不可想象！😱
我们需要更聪明的方法 → 二分答案！

⚡ 核心算法：二分答案 + 贪心检查

💡 关键思想：反转问题！

原问题：分成 M 段，让最大段和 最小。

反转成：
猜一个上限 x → 问：如果每段的和不超过 x，最少需要分多少段？
• 如果需要的段数 ≤ M → x 够大（可行），尝试更小的 x
• 如果需要的段数 > M → x 太小（不可行），必须增大 x

答案有单调性：
x 越大 → 每段能装更多 → 需要的段数越少 → 越容易可行
x 越小 → 每段装得少 → 需要的段数越多 → 越难满足

🔍 二分范围怎么定？

📉 下界 lo = max(A)

每段至少包含一个元素。
最大的元素一定在某一段里。
所以每段上限不能小于 max(A)！
样例1：lo = max(4,2,4,5,1) = 5

📈 上界 hi = sum(A)

最极端情况：全部放一段。
此时最大段和 = 数组总和。
不可能比这更大了。
样例1：hi = 4+2+4+5+1 = 16

✨ 二分答案模板（找最小可行值）✨
lo = max(A), hi = sum(A)
while lo < hi:
  mid = (lo + hi) / 2
  if check(mid) ≤ M: hi = mid
  else: lo = mid + 1
答案 = lo
注意：我们要找最小的可行值，所以用"下中位数 + hi=mid"模板

🔍 check(x)：贪心检查怎么做？

思路：从左到右贪心装箱，每段装尽量多！

维护：curSum = 当前段已累积的能量，cnt = 段数（初始 = 1）

遍历每个箱子的能量 A[i]：

  • 如果 curSum + A[i] ≤ x（还装得下）→ 放入当前段，curSum += A[i]
  • 如果 curSum + A[i] > x（超载了！）→ 新开一段，cnt++，curSum = A[i]

最终：cnt ≤ M → x 可行！

💡 为什么贪心是正确的？

每段尽量多装 → 用最少的段数。
如果最少段数 ≤ M，说明 M 段肯定够用。
（段数多了，可以把某段拆成两段，不会让最大值变大。）
所以：贪心得到的段数就是"最少需要的段数"。

⏱️ 复杂度分析

步骤 操作 复杂度
二分轮数 在 [max(A), sum(A)] 中二分 O(log S) ≈ 30 轮
每轮 check 遍历 N 个元素 O(N)
总计 30 × 100000 O(N log S) ≈ 300万 ⚡
S = sum(A) ≤ 10⁹，log₂(10⁹) ≈ 30。轻松通过！💪

⚠️ 细节与注意事项

🚨 细节1：下界必须是 max(A)，不能是 0！

如果某个元素 A[i] = 10，那么包含它的段至少要 ≥ 10。
如果 x < max(A)，连一个元素都装不下，永远不可行！
所以 lo = max(A) 是正确的下界。

🚨 细节2：使用 long long 避免溢出！

N ≤ 10⁵，A[i] < 10⁸ → sum(A) 最大约 10¹³
超出 int 范围（约 2×10⁹）！
C++ 中 sum 和 hi 必须用 long long。
Python 不用担心，整数没有上限。

💡 细节3：cnt < M 也是可行的！

贪心得到 cnt 段。如果 cnt < M（段数不够），没关系！
可以把某些段拆开凑够 M 段，拆开只会让最大值变小或不变。
所以 cnt ≤ M 就是可行的。

📘 C++ 知识点

  • 🔍 二分答案模板： while(lo < hi) + 下中位数 mid = (lo+hi)/2，寻找最小可行值。
  • 🟢 贪心 check 函数： 从左到右扫描，能放就放，放不下就开新段。O(N)。
  • 📦 long long： sum(A) 可能高达 10¹³，必须用 long long。
  • ⚡ *max_element / accumulate： STL 快速求最大值和总和。

💻 C++ 代码

#include <iostream>
#include <algorithm>
using namespace std;

int N, M;
long long a[100005];

// 🟢 贪心检查：每段和 ≤ limit，最少需要几段？
int check(long long limit) {
    int cnt = 1;          // 段数，从 1 开始
    long long curSum = 0;  // 当前段已累积的和

    for (int i = 0; i < N; i++) {
        if (curSum + a[i] <= limit) {
            // 📦 还装得下，放入当前段
            curSum += a[i];
        } else {
            // ✂️ 超载了，新开一段
            cnt++;
            curSum = a[i];
        }
    }
    return cnt;
}

int main() {
    cin >> N >> M;

    long long maxVal = 0, sum = 0;
    for (int i = 0; i < N; i++) {
        cin >> a[i];
        maxVal = max(maxVal, a[i]);
        sum += a[i];
    }

    // 🔍 二分答案：在 [maxVal, sum] 中找最小的可行值
    long long lo = maxVal, hi = sum;
    while (lo < hi) {
        long long mid = (lo + hi) / 2;  // 下中位数
        if (check(mid) <= M) {
            hi = mid;       // ✅ 可行，尝试更小
        } else {
            lo = mid + 1;   // ❌ 不可行，增大下界
        }
    }

    cout << lo << endl;
    return 0;
}

🐍 Python 知识点

  • 🔍 二分答案模板： while lo < hi + 下中位数 mid = (lo+hi)//2。
  • 🟢 贪心 check 函数： 一次遍历，O(N)。
  • ⚡ sys.stdin 加速： N 最大 10⁵，建议用 sys.stdin 读入。
  • 🐍 大整数无忧： Python 整数没有上限，无需担心溢出。

💻 Python 代码

import sys
input = sys.stdin.readline

def check(limit):
    """贪心检查：每段和 ≤ limit，最少需要几段？"""
    cnt = 1        # 段数
    cur_sum = 0    # 当前段的和

    for x in A:
        if cur_sum + x <= limit:
            cur_sum += x   # 📦 放入当前段
        else:
            cnt += 1       # ✂️ 新开一段
            cur_sum = x

    return cnt

# 📥 读入
N, M = map(int, input().split())
A = list(map(int, input().split()))

# 🔍 二分答案
lo = max(A)    # 下界：最大单个元素
hi = sum(A)    # 上界：全部总和

while lo < hi:
    mid = (lo + hi) // 2
    if check(mid) <= M:
        hi = mid        # ✅ 可行，尝试更小
    else:
        lo = mid + 1    # ❌ 不可行

print(lo)

🧩 两题对比：不同的二分模板

🪨 上一题：冰川踏石
目标：最大化最小跳跃距离
→ 找最大的可行值
→ 上中位数 + lo=mid

mid = (lo+hi+1)/2
if ok: lo = mid
else: hi = mid-1
📦 本题：雪岭分卷
目标：最小化最大段和
→ 找最小的可行值
→ 下中位数 + hi=mid

mid = (lo+hi)/2
if ok: hi = mid
else: lo = mid+1
💡 如何记住用哪个模板？

找最大可行值 → lo=mid → mid 用上中位数（+1）防死循环
找最小可行值 → hi=mid → mid 用下中位数（不加1）防死循环

口诀："找大 lo 上升 +1，找小 hi 下降 不+1"

每段只有一个元素 → 答案 = max(A)

只有一段 → 答案 = sum(A)

💡 技巧和重点总结 (划重点啦)

  • 🎯 二分答案思想： 不直接求"最优分法"，而是猜一个"每段上限 x"，检查"x 是否够用"。利用答案的单调性，用二分找到最小的可行 x。这是"最小化最大值"类问题的标准武器！
  • 🟢 贪心 check 函数： 从左到右遍历，每段尽量多装，超限就新开一段。统计段数 cnt，若 cnt ≤ M 就可行。时间 O(N)，简单高效。
  • 📏 二分范围： 下界 lo = max(A)（一个元素不能拆），上界 hi = sum(A)（全放一段）。二分轮数 ≈ log₂(sum) ≈ 30 次。
  • 🔢 注意 long long： C++ 中 sum(A) 可能超过 int 范围！hi、mid、curSum 都要用 long long。Python 不受影响。
  • 📐 找最小可行值的模板： mid=(lo+hi)/2（下中位数），可行时 hi=mid，不可行时 lo=mid+1。和上一题（找最大可行值）相反，注意区分！
