📜 任务清单 (题目描述)

n 天，每天有 ri 间教室。m 份申请按顺序处理（先到先得）。

第 j 份申请：从第 sj 天到第 tj 天，每天需要 dj 间教室。

目标：判断所有申请能否满足；若不能，找出第一个失败的申请编号。

📐 输入输出格式：
• 输入：第1行 n, m；第2行 n 个整数 ri；接下来 m 行每行 dj, sj, tj
• 输出：若全部满足输出 0；否则先输出 -1，再输出第一个失败的编号
• 数据范围：n, m ≤ 106，ri, dj ≤ 109

📚 前置知识：差分数组

💡 差分数组是什么？

对一个区间 [s, t] 上的所有元素加上 d，暴力需要 O(t-s+1)。
用差分数组只需 O(1)：
diff[s] += d，diff[t+1] -= d

之后做一次前缀和就能还原出每个位置的实际值！

⚡ 核心算法：二分答案 + 差分检查

💡 关键思想：二分"前 x 份申请"！

观察单调性：
• 如果前 x 份申请能满足 → 前 x-1 份也一定能满足 ✅
• 如果前 x 份申请不能满足 → 前 x+1 份也一定不能满足 ❌

这是完美的单调性！可以二分找到"分界点"：
✅✅✅ ... ✅ ❌❌❌ ... ❌
第一个 ❌ 就是答案！

🔍 check(mid) 怎么实现？

用差分数组快速计算前 mid 份申请的总需求！

  1. 初始化差分数组 diff[1..n+1] = 0
  2. 对前 mid 份申请，执行差分操作：
    diff[s_j] += d_j，diff[t_j+1] -= d_j
  3. 计算前缀和 → 得到每天的总需求 need[i]
  4. 检查：是否每天都有 need[i] ≤ r[i]？

时间复杂度：O(mid + n) ≈ O(n + m)

✨ 完整算法流程 ✨
先 check(m)：全部可行 → 输出 0
否则：二分找第一个失败的申请
lo = 1, hi = m
while lo < hi:
  mid = (lo + hi) / 2
  if check(mid): lo = mid + 1
  else: hi = mid
输出 -1 和 lo
check(mid) = true 表示前 mid 份可行 → 失败在后面 → lo = mid+1
check(mid) = false 表示前 mid 份不可行 → 失败在 ≤ mid → hi = mid

⏱️ 复杂度分析

步骤 操作 复杂度
二分轮数 在 [1, m] 中二分 O(log m) ≈ 20 轮
每轮 check 差分 O(mid) + 前缀和 O(n) O(n + m)
总计 20 × (n + m) O((n+m) log m) ≈ 4千万 ⚡
n, m ≤ 10⁶，log₂(10⁶) ≈ 20。远快于暴力的 O(nm) = 10¹²！

⚠️ 细节与注意事项

🚨 细节1：先特判全部可行的情况！

先调用 check(m)，如果返回 true → 直接输出 0，不用二分。
否则才进行二分查找第一个失败的申请编号。

🚨 细节2：使用 long long 避免溢出！

dj 和 ri 最大可达 10⁹。多份申请的区间可能重叠，
前缀和累加后可能超过 int 范围 → 差分数组和前缀和必须用 long long。
Python 自动支持大整数，不用担心。

🚨 细节3：差分数组大小要开 n+2！

操作 diff[t_j+1] -= d_j 中，t_j 最大为 n，
所以 t_j+1 最大为 n+1 → 数组大小至少 n+2。

🚨 细节4：每次 check 需要清空差分数组！

每次 check(mid) 都是独立判断"前 mid 份能否满足"。
所以每次需要从零开始构建差分数组，不能复用上次的。
C++ 中可在函数内新建 vector<long long>，约 20 次 × O(n) = 2千万，可以接受。

📘 C++ 知识点

  • 🔍 二分答案： 找第一个使 check 失败的位置，即"找最小不可行值"模板。
  • 📊 差分数组： diff[s]+=d, diff[t+1]-=d，前缀和还原每个位置的实际值。区间加 O(1)，整体还原 O(n)。
  • 📦 long long： 多个申请重叠累加可能溢出 int，必须用 long long。
  • ⚡ IO 加速： n, m ≤ 10⁶，务必用 ios::sync_with_stdio(false)。

💻 C++ 代码

#include <iostream>
#include <vector>
using namespace std;

int n, m;
long long r[1000005];       // 每天可用教室数
int d[1000005], s[1000005], t[1000005]; // 申请信息

// 🟢 check：前 mid 份申请是否全部可行？
bool check(int mid) {
    // 📊 构建差分数组
    vector<long long> diff(n + 2, 0);

    for (int j = 1; j <= mid; j++) {
        diff[s[j]] += d[j];       // 区间起点 +d
        diff[t[j] + 1] -= d[j];   // 区间终点+1 -d
    }

    // 📈 前缀和还原每天需求，并与 r[i] 比较
    long long need = 0;
    for (int i = 1; i <= n; i++) {
        need += diff[i];
        if (need > r[i]) {
            return false;  // 💥 第 i 天教室不够！
        }
    }
    return true;  // ✅ 全部满足
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    cin >> n >> m;
    for (int i = 1; i <= n; i++) cin >> r[i];
    for (int j = 1; j <= m; j++) cin >> d[j] >> s[j] >> t[j];

    // 🎯 特判：全部可行？
    if (check(m)) {
        cout << 0 << endl;
        return 0;
    }

    // 🔍 二分查找第一个失败的申请编号
    int lo = 1, hi = m;
    while (lo < hi) {
        int mid = (lo + hi) / 2;
        if (check(mid)) {
            lo = mid + 1;   // ✅ 前 mid 份可行，失败在后面
        } else {
            hi = mid;       // ❌ 前 mid 份不可行，失败在 ≤mid
        }
    }

    cout << -1 << endl;
    cout << lo << endl;
    return 0;
}

🐍 Python 知识点

  • 🔍 二分答案： 和 C++ 逻辑完全相同。找第一个使 check 失败的位置。
  • 📊 差分数组： 用列表 [0]*(n+2) 实现。
  • ⚡ 快速 IO： n, m ≤ 10⁶ 数据量巨大，必须用 sys.stdin.buffer.read() 一次性读入！
  • 🐍 大整数无忧： Python 整数没有上限，不用担心溢出。

💻 Python 代码

import sys

def main():
    data = sys.stdin.buffer.read().split()
    idx = 0

    def rd():
        nonlocal idx
        idx += 1
        return int(data[idx - 1])

    n, m = rd(), rd()
    r = [0] + [rd() for _ in range(n)]  # r[1..n]

    d_arr = [0] * (m + 1)
    s_arr = [0] * (m + 1)
    t_arr = [0] * (m + 1)
    for j in range(1, m + 1):
        d_arr[j], s_arr[j], t_arr[j] = rd(), rd(), rd()

    def check(mid):
        """前 mid 份申请是否全部可行？"""
        diff = [0] * (n + 2)

        for j in range(1, mid + 1):
            diff[s_arr[j]] += d_arr[j]
            diff[t_arr[j] + 1] -= d_arr[j]

        # 📈 前缀和还原
        need = 0
        for i in range(1, n + 1):
            need += diff[i]
            if need > r[i]:
                return False
        return True

    # 🎯 特判
    if check(m):
        print(0)
        return

    # 🔍 二分查找第一个失败编号
    lo, hi = 1, m
    while lo < hi:
        mid = (lo + hi) // 2
        if check(mid):
            lo = mid + 1
        else:
            hi = mid

    print(-1)
    print(lo)

main()

⚖️ 为什么用差分数组？

对比项 暴力模拟 差分数组
处理一份申请 遍历 [s,t]，逐天扣减 → O(n) 两个端点操作 → O(1)
处理 mid 份申请 O(n × mid) O(mid) + O(n) 前缀和
总复杂度 O(nm) ≈ 10¹² 😱 O((n+m) log m) ≈ 4×10⁷ ⚡

🧩 二分模板：这道题用哪个？

🏫 本题：找第一个失败的编号
前 x 份可行 → 失败在 x+1 或更后面
前 x 份不可行 → 失败在 x 或更前面

→ 找最小的不可行 x

mid = (lo+hi) / 2
if check(mid): lo = mid + 1
else: hi = mid
📝 记忆口诀
✅✅✅ ... ✅ ❌❌❌ ... ❌

check(mid) = ✅ → 答案在右边 → lo = mid + 1
check(mid) = ❌ → 答案可能就是 mid → hi = mid

最终 lo == hi 就是第一个 ❌ 的位置

✅ 样例验证

样例 1：n=4, m=3
check(3)=❌ → 开始二分
check(2)=❌ → hi=2，check(1)=✅ → lo=2
输出：-1 \n 2 ✅
样例 2：n=5, m=4
check(4)=✅ → 全部可行
输出：0 ✅
样例 3：n=6, m=5
check(5)=❌ → 开始二分
check(4)=✅ → lo=5，lo==hi=5
输出：-1 \n 5 ✅
边界：m=1，且第1份就失败
check(1)=❌，check(0) 不需要调用（lo=hi=1）
输出：-1 \n 1 ✅
边界：所有申请 d=0
不需要任何教室 → check(m)=✅ → 输出 0 ✅

💡 技巧和重点总结 (划重点啦)

  • 🎯 二分答案核心： "前 x 份申请能否满足"具有单调性——一旦某份失败，之后的也一定失败。二分找到第一个失败的位置，就是答案。
  • 📊 差分数组加速： 每份申请是"区间 [s,t] 上每天需要 d 间教室"。用差分数组，一次区间加只需 O(1)，再通过前缀和还原每天的总需求。这是处理大量区间操作的核心技巧！
  • ⚡ 总体复杂度： 二分 O(log m) 轮 × 每轮差分 O(n+m) = O((n+m) log m)。当 n=m=10⁶ 时约 4 千万次操作，轻松通过！
  • 🛡️ 先特判再二分： 先 check(m)，全可行直接输出 0。否则再二分找答案。别忘了这个特判！
  • 🔢 注意 long long： 多个申请的需求叠加可能极大（最多 10⁶ 个 10⁹ 重叠），C++ 中差分数组和前缀和必须用 long long。Python 不受影响。
