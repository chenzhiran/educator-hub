02三系魔力与采集循环THE RESOURCE LOOP

把魔力想成三个小罐子：火罐子、水罐子和土罐子。果农带回哪种水果，就为对应的小罐子补充魔力。三种魔力不能互相替代。

火系 fire

黄色的火系水果，提供火魔力。火箭、火球等法术会用到它。

水系 water

蓝色的水系水果，提供水魔力。水箭、水盾等法术会用到它。

土系 earth

绿色的土系水果，提供土魔力。土箭、土生长等法术会用到它。

练习：找到指定位置的火果

findFruits() 找到水果列表；pos 中的 x、y 表示位置；mana 表示水果元素。这里去掉坐标的小数后再比较。

def has_opening_fire_fruit():
    for fruit in hero.findFruits():
        if (int(fruit.pos["x"]) == 44
                and int(fruit.pos["y"]) == 48
                and fruit.mana == "fire"):
            return True
    return False
bool has_opening_fire_fruit() {
    for (auto fruit : hero.findFruits()) {
        if (static_cast<int>(fruit.pos["x"]) == 44 &&
            static_cast<int>(fruit.pos["y"]) == 48 &&
            fruit.mana == "fire") {
            return true;
        }
    }
    return false;
}

开局你已经有 1 位果农。使用 hero.spawnCollector() 可以再叫来一位。果农越多，采集的小帮手越多；不过，后面来的果农要等更久。

看表小窍门：第 3 位果农要等 3 秒，是这一次生成要用的时间，不是从开局算起的总时间。生成果农时不能攻击，要选好时机。

练习：开局连续生成四位果农

这是优化程序的开局安排：连续调用四次 spawnCollector()。开局自带一位，因此这是再生成四位，不是把总人数设成四位。

for collector_number in range(4):
    hero.spawnCollector()
for (int collector_number = 0; collector_number < 4; ++collector_number) {
    hero.spawnCollector();
}

选果回调：按队伍颜色返回坐标

前 55 秒，红方去 (60, 42)，蓝方去 (40, 42)。Python 把包含 x、y 的字典返回给果农。55 秒以后函数返回 None，不再指定坐标。

Python · 竞技场选果回调
def choose_fruit(collector):
    if hero.time < 55:
        if hero.color == "red":
            return {"x": 60, "y": 42}
        return {"x": 40, "y": 42}

hero.chooseItem = choose_fruit

绑定函数时写 choose_fruit，不加括号。C++ 的坐标回调需要编辑器提供具体的返回类型，不能直接套用 Python 字典。

04施法条件与完整数值SPELLBOOK · ALL 15 SPELLS

释放法术要有足够的对应魔力，并等待冷却结束。canCast 可以检查是否就绪；优化程序则保留原有策略条件后调用 cast，两种检查不要混为一谈。

不必自己猜能不能放。hero.canCast("法术名字") 会帮你检查；检查通过后，再用 hero.cast("法术名字") 施法。

补充：检查法术是否已经就绪

这是独立的安全施法写法。它不是优化程序中的原有判断，不会自动改变优化程序的行为。

if hero.canCast("water-arrow"):
    hero.cast("water-arrow")
if (hero.canCast("water-arrow")) {
    hero.cast("water-arrow");
}

练习：读取魔力并选择水箭

先检查进攻条件，再尝试施法。这里展示的是比赛策略条件；它不等于 canCast 的施法就绪检查。

enemy_hero = hero.getEnemyHero()
if hero.water >= 6 or hero.time > 100:
    if enemy_hero.fire < 4.3 or hero.fire >= 3:
        hero.cast("water-arrow")
auto enemy_hero = hero.getEnemyHero();
if (hero.water >= 6 || hero.time > 100) {
    if (enemy_hero.fire < 4.3 || hero.fire >= 3) {
        hero.cast("water-arrow");
    }
}

hero.earth 是我方土魔力；enemy_hero.water 是对手水魔力。两层 if 都通过才尝试放土箭。

enemy_hero = hero.getEnemyHero()

06护盾与元素克制ELEMENTAL COUNTERS

护盾像一面魔法盾牌。火盾、水盾、土盾都需要 3 点对应元素的魔力。面对不同的攻击，要选择合适的护盾。

对手放来的攻击我们选什么盾为什么
火系攻击water-shield 水盾水克火
水系攻击earth-shield 土盾土克水
土系攻击fire-shield 火盾火克土
记住小口诀：水挡火，土挡水，火挡土。会选择还不够，放盾的时机也很重要。

练习：遇到火系球或火系束时选盾

先选克制火的水盾；水魔力不足，再考虑火盾。这里只演示选盾，完整程序还会先检查飞行法术的位置。

enemy_missiles = hero.findEnemyMissiles()
for missile in enemy_missiles:
    if missile.type in ("fire-ball", "fire-beam"):
        if hero.water >= 3:
            hero.cast("water-shield")
        elif hero.fire >= 3:
            hero.cast("fire-shield")
        break
auto enemy_missiles = hero.findEnemyMissiles();
for (auto missile : enemy_missiles) {
    if (missile.type == "fire-ball" || missile.type == "fire-beam") {
        if (hero.water >= 3) {
            hero.cast("water-shield");
        } else if (hero.fire >= 3) {
            hero.cast("fire-shield");
        }
        break;
    }
}

练习：满足三个条件才选择火燃烧

开局检查结果、时间和敌方果农数量都合适时，才进入火燃烧分支。单独练习时先执行 has_opening_fire_fruit 函数及开局赋值。

opening_has_fire_fruit = has_opening_fire_fruit()
if (opening_has_fire_fruit
        and hero.time < 90
        and len(hero.findEnemyCollectors()) > 2):
    hero.cast("fire-burn")
bool opening_has_fire_fruit = has_opening_fire_fruit();
if (opening_has_fire_fruit &&
    hero.time < 90 &&
    hero.findEnemyCollectors().size() > 2) {
    hero.cast("fire-burn");
}
