🧠 魔法道具箱 (核心图解)

为什么目标是"最大值"而不是"平均值"？

因为国王只能给钱、不能收钱！如果用平均值做目标，比最有钱的人还少，那最有钱的人就得被收钱——不允许！
所以唯一的选择是：把所有人都补齐到最有钱的那个人的水平。

📘 C++ 写法一 · 知识点

  • 🔢 数组存储： int a[105] 开105大小的数组（比100稍大一点，防止越界），存放每个人的金币数。
  • 🏆 求最大值模式： 先把 m 设为一个极小的初始值，然后遍历数组，遇到更大的就更新。这是求最大值的经典写法！
  • ➕ 累加模式： 初始化 b = 0，每次把差值加上去。这也是"求和"的经典写法。

💻 C++ 两次遍历代码

#include <iostream>
using namespace std;

int n, a[105];
int m = 0, b = 0;  // m: 最大值, b: 需要发的总金币

int main() {
    cin >> n;

    // 读入每个人的金币
    for (int i = 0; i < n; i++)
        cin >> a[i];

    // 🔎 第1次遍历：找到最有钱的人
    for (int i = 0; i < n; i++) {
        if (a[i] > m)
            m = a[i];  // 更新最大值
    }

    // ➕ 第2次遍历：累加每个人的差值
    for (int i = 0; i < n; i++) {
        b += m - a[i];  // 需要补多少就加多少
    }

    cout << b;
    return 0;
}

🐍 Python 写法一 · 知识点

  • 📦 列表读入： list(map(int, input().split())) 一行代码把空格分隔的数字读成列表！
  • 🏆 内置max函数： Python 的 max(列表) 直接返回列表中的最大值，不用手写循环找！
  • ➕ for循环累加： 遍历列表，把每个差值加到 total 上。

💻 Python 两次遍历代码

# 读入数据
n = int(input())
coins = list(map(int, input().split()))

# 🔎 找到最有钱的人
max_coins = max(coins)

# ➕ 累加每个人的差值
total = 0
for c in coins:
    total += max_coins - c  # 需要补多少就加多少

print(total)

⚡ 写法二：一次遍历（公式法）

聪明的财务大臣发现了一个数学捷径！不需要逐个算差值，用一个简洁的公式就搞定！

💡 公式推导

每个人都需要补齐到 max，总共需要：
(max - a[0]) + (max - a[1]) + ... + (max - a[n-1])
= max × n - (a[0] + a[1] + ... + a[n-1])
= max × n - sum

✨ 所以只要算出 最大值 和 总和，一步到位！

一次循环
🔎 同时找 max
➕ 同时算 sum
→
公式计算
max × n − sum
→
输出结果
📤 一步到位！
📋 样例 1 用公式法验证：
金币 = [3, 2, 4, 1]

max = 4    n = 4    sum = 3+2+4+1 = 10

答案 = max × n − sum = 4 × 4 − 10 = 16 − 10 = 6 💰
公式的几何意义：大矩形面积 − 柱子面积 = 补齐面积

📘 C++ 写法二 · 知识点

  • ⚡ 一趟搞定两件事： 在同一个 for 循环里，既更新最大值 m，又累加总和 s。
  • 🧮 公式代替循环： 用 m * n - s 一步计算出答案，不需要第二次遍历。代码更短更快！
  • 💡 变量复用思想： 一次循环中可以同时维护多个变量（max、sum），这是编程中很常见的优化技巧。

💻 C++ 公式法代码

#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;

    int a[105];
    int m = 0, s = 0;  // m: 最大值, s: 总和

    // ⚡ 一次循环：同时找最大值 + 算总和
    for (int i = 0; i < n; i++) {
        cin >> a[i];
        if (a[i] > m)
            m = a[i];    // 更新最大值
        s += a[i];       // 累加总和
    }

    // 🧮 公式一步到位：max × n − sum
    cout << m * n - s;

    return 0;
}

🐍 Python 写法二 · 知识点

  • ⚡ 内置函数组合拳： max() 找最大值 + sum() 求总和，两个内置函数直接搞定！
  • 🧮 公式代替循环： max(coins) * n - sum(coins)，一行代码就是答案！
  • ✨ Python 之美： 利用 Python 丰富的内置函数，代码可以写得极其简洁。

💻 Python 公式法代码

# 读入数据
n = int(input())
coins = list(map(int, input().split()))

# 🧮 公式一步到位：max × n − sum
print(max(coins) * n - sum(coins))

💡 技巧和重点总结 (划重点啦)

  • 👑 目标确定： 在"只发不收"的规则下，每个人的目标金币数只能是 最大值！如果用平均值，比最大值还少的话，最有钱的人就得被收钱了——这违反规则。
  • 🔍 求最大值模式： 初始化 m = 0（或极小值），遍历数组，遇到更大的就更新。这是编程中最基础也最重要的模式之一！
  • ➕ 累加模式： 初始化 total = 0，循环中不断地 total += 某个值。求和、计数、累积差值都用这个套路。
  • 🧮 数学简化： 很多"逐个计算再累加"的问题，都可以用代数公式简化。Σ(max−a[i]) = max×n − Σa[i]，这种化简能力在竞赛中很有用！
