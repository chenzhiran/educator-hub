相对移动 (Relative Move)

[Image of vector addition diagram]

在当前位置的基础上进行加减，实现“向左走”或“向右走”。

while(true) { float x = hero.pos.x; float y = hero.pos.y; // 向右走：X + 10 x += 10; // 向左走：X - 10 // x -= 10; hero.moveXY(x, y); }

斜线飞行 (Diagonal)

同时改变 X 和 Y，就能走出斜线！

while(true) { // 向右上方飞: X加, Y加 auto newX = hero.pos.x + 5; auto newY = hero.pos.y + 5; hero.moveXY(newX, newY); }

相对建造 (Relative Build)

不仅可以移动自己，还可以在别人旁边造东西。

if (enemy) { // 在敌人左边 20 米处造围栏 float buildX = enemy.pos.x - 20; float buildY = enemy.pos.y; hero.buildXY("fence", buildX, buildY); }
"拦截敌人的必经之路！"

方向判断 (Compare Coords)

比较坐标大小，就能知道敌人的方位：

if (enemy.pos.x < hero.pos.x) { // 敌人的X更小 -> 敌人在左边 hero.buildXY("fire-trap", 25, 34); } else if (enemy.pos.x > hero.pos.x) { // 敌人的X更大 -> 敌人在右边 hero.buildXY("fire-trap", 55, 34); }
👆 Y > Hero.Y
👈 X < Hero.X 🤖 👉 X > Hero.X
👇 Y < Hero.Y
➗

中点计算 (Midpoint)

想站在朋友和敌人中间？用平均数公式！

// 计算 X 的中点 float midX = (friend.pos.x + enemy.pos.x) / 2; // 计算 Y 的中点 float midY = (friend.pos.y + enemy.pos.y) / 2; hero.moveXY(midX, midY);
数学原理：(A + B) / 2 = 中间值

垂直追踪 (Vertical Logic)

if (yak.pos.y > hero.pos.y) { // 敌人在上方，我要往下建墙 hero.buildXY("fence", x, y - 10); } else { // 敌人在下方，我要往上建墙 hero.buildXY("fence", x, y + 10); }
