严格检查官：&&

在 C++ 中，AND 写作 &&。

它就像一个超级严格的检查官，只有所有条件全部满足，才肯放行。

  • ✅ True && True = True
  • ❌ True && False = False
  • ❌ False && True = False
  • ❌ False && False = False
// 既要是特定种族，又要血量低 if (type == "burl" && health < 10) { heal(unit); }
