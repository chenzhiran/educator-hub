反向大师：NOT (!)

01/08

在 C++ 中，NOT 写作 !。

它就像一面魔法镜子，会把 true 变成 false，把 false 变成 true。

// 例子：如果没有下雨 bool is_raining = true; bool can_go_out = !is_raining; // 结果：false (不能出去)
"非真即假，非假即真。"

根据布尔运算结果选择路径。

// 1. AND (&&): 两个都为真 if (secretA && secretB) hero.moveXY(20, 33); else hero.moveXY(20, 15); // 2. OR (||): 至少一个为真 if (secretA || secretB) hero.moveXY(32, 33); else hero.moveXY(32, 15); // 3. NOT (!): 取反 if (!secretB) hero.moveXY(44, 33); else hero.moveXY(44, 15);

谁先谁后？(优先级)

05/08

逻辑运算符的计算顺序：

1. ( ) 括号 - 最高
2. ! (NOT) - 取反
3. && (AND) - 并且
4. || (OR) - 或者
"C++ 先算 !，再算 &&，最后算 ||。
拿不准时，请用括号！"
