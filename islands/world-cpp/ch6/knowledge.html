关卡1：update事件处理

事件绑定
Logic

单位的update处理器：每帧检查并行动。

auto onUpdateUnit(auto event) { auto unit = event.target; auto enemy = unit.findNearestEnemy(); if (enemy && shouldAttack(unit, enemy)) { unit.attack(enemy); } else { // 没有合适目标就反向移动 if (unit.team == "ogres") { unit.moveXY(unit.pos.x - 3, unit.pos.y); } else { unit.moveXY(unit.pos.x + 3, unit.pos.y); } } // 屏幕外的单位直接销毁 if (unit.pos.x > 80 || unit.pos.x < 0) unit.destroy(); }
绑定事件：
game.setActionFor("scout", "update", onUpdateUnit);
⚡ update事件 vs while循环
❌ 旧方式
while(true) {
  checkEnemy();
}
✅ 新方式
game.setActionFor(
  "scout",
  "update",
  onUpdateUnit);
优势：
✅ 可以按需添加/移除处理器
✅ 更好的性能控制
✅ 代码更清晰

关卡3：量子跃迁

pos修改
Phys
核心发现：直接修改 pos.x 和 pos.y 可以瞬间改变位置！

两种修改方式：

// 方式1：相对移动（加减） unit.pos.y -= 10; // 向下移动10 unit.pos.x += 5; // 向右移动5 // 方式2：绝对定位（直接设值） unit.pos.x = 40; // 传送到x=40
性能技巧：不销毁+重生，而是直接传送回起点！
// 食人魔移出屏幕后传送回来 if (unit.pos.x > 80) { unit.pos.x = 0; // 回到左边重来 }
点击传送！

关卡4：循环森林

折回机制
Phys
Wraparound（折回）：走出左边 → 出现在右边！常用游戏技巧。
auto onUpdate(auto event) { auto unit = event.target; // 左边太远 → 传送到右边 if (unit.pos.x < 10) unit.pos.x = 68; // 右边太远 → 传送到左边 if (unit.pos.x > 70) unit.pos.x = 12; // 上下方向同理！ if (unit.pos.y < 10) unit.pos.y = 56; if (unit.pos.y > 58) unit.pos.y = 12; }
同一处理器复用：玩家和食人魔都绑定 onUpdate！
player.on("update", onUpdate);
game.setActionFor("munchkin", "update", onUpdate);

关卡5：平稳移动

逐帧运动
Phys
平滑移动 = 每帧移动一点点
速度 × 方向 = 每帧位移量
// 移动围栏（上下弹跳） auto onUpdateFence(auto event) { auto fence = event.target; // speed × direction = 位移 float dist = fenceSpeed * fence.dir; fence.pos.y += dist; // 到达边界就反弹 if (fence.pos.y > 56 || fence.pos.y < 10) { fence.dir *= -1; // 反转方向！ } }
dir 方向值：
dir = 1 → 向上/右移动
dir = -1 → 向下/左移动
dir *= -1 → 反转方向（弹跳！）

关卡6：发狂的宝石

2D运动
Game
X + Y 两个方向同时移动 = 对角线！像台球一样弹跳。
auto onUpdate(auto event) { auto item = event.target; // X轴和Y轴分别移动 auto diffX = item.dirX * gemSpeed; auto diffY = item.dirY * gemSpeed; item.pos.x += diffX; item.pos.y += diffY; // X方向弹跳 if (item.pos.x > 70 || item.pos.x < 10) item.dirX *= -1; // Y方向弹跳 if (item.pos.y > 58 || item.pos.y < 10) item.dirY *= -1; }
随机方向：dirX/dirY 可取 -1、0、1
0 = 该方向不动 → 纯水平/垂直运动
