什么是“平衡” (Balance)？

游戏太简单 → 无聊。
游戏太难 → 生气。

平衡就是通过调整参数，找到那个“刚刚好”的点：

  • 😰 Too Hard: 敌人太强，玩家一直输。
  • 😴 Too Easy: 敌人太弱，玩家睡着了。
  • 🤩 Just Right: 有挑战，但这能赢！
😈
😊
🎛️

工具：常量 (Constant)

我们在代码最上面定义一组“全大写”的变量，这就是游戏的配置面板。

// 游戏参数配置 auto HERO_SPEED = 20; auto OGRE_SPEED = 10; auto POWER_TIME = 4;
"就像写在黑板上的规则：全大写，表示这是固定配置，不要随便在别处乱改。"
🎚️ ⚙️ 🔧

Difficulty Knobs
(难度旋钮)

🪄

拒绝“魔法数字”

魔法数字 (Magic Number)：
代码里突然出现的裸数字，没人知道它是干嘛的。

使用常量可以让代码变成“说明书”：

Bad
if(item.type == "coin") {
  game.score += 1 // 这是啥?
}
Good
COIN_SCORE = 1
if(item.type == "coin") {
  game.score += COIN_SCORE
}
🌊

参数如何生效？

参数是在游戏开始时“流”进对象里的。

// 1. 定义参数 auto HERO_SPEED = 22; // 2. 应用到对象 player.maxSpeed = HERO_SPEED;

当你修改顶部的 HERO_SPEED，下面的 player 就会自动变快。

HERO_SPEED = 22
⬇️ 赋值
🤠
maxSpeed: 22
🏎️

实验 1：速度平衡

如果英雄比敌人快太多，游戏就太简单；如果比敌人慢，就太难。

实验 2：风险与回报

去吃蘑菇需要绕路（花时间）。

  • ⏳ 时间成本：绕路 5 秒 ≈ 扣 2.5 分
  • 🎁 蘑菇回报：+5 分 + 杀敌分
"如果回报 < 成本，玩家就不会去做了。设计时要保证：收益 > 风险！"
