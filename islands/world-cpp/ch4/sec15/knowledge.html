Power-up vs 升级

能力强化 (Power-up) 是短时间的爆发：
像吃了星星的马里奥，或者开了大的超级赛亚人。

  • ⏳ 有时限：比如持续 6 秒。
  • 📈 变强：体型变大，攻击力爆表。
与“升级 (Upgrade)”不同，升级是永久的，而 Power-up 时间一到就会消失。
⭐
INVINCIBLE!
(For 6 seconds)
🦸

形态切换：Up & Down

我们定义两个函数来切换形态：

auto powerPlayerUp() { player.scale = 2; // 变大 player.attackDamage = 100; // 变强 } auto powerPlayerDown() { player.scale = 1; // 恢复 player.attackDamage = 1; }
🤠
Scale: 1
🧮

时间计算公式

我们要计算强化什么时候结束：

game.powerEndTime = game.time + 6;

公式： 结束时间 = 当前时间 + 持续时间

剩余时间 = 结束时间 - 当前时间

EndTime

吃蘑菇变身

把变身逻辑放在收集事件里：

auto onCollect(auto event) { auto item = event.other; if (item.type == "mushroom") { powerPlayerUp(); // 启动! } }

只有捡到蘑菇才会变身，捡金币只加分。

反杀敌人：onCollide

变身后，碰到敌人不再受伤，而是直接消灭它！

if (other.type == "scout" && player.scale == 2) { other.defeat(); }
逻辑与 (&&)：
必须同时满足“是敌人”且“我是巨人”，才能反杀。

敌人也会怕

敌人会检查你的状态：

if (player.scale == 2) { unit.behavior = "RunsAway"; } else { unit.behavior = "AttacksNearest"; }

你变强，它就逃跑；你变弱，它就追你。

🤠
👾
好可怕!
⏳

时间到：打回原形

每一帧都要检查时间：

auto remain = game.endTime - game.time; if (remain <= 0) { if (player.scale == 2) { powerPlayerDown(); } }

倒计时结束，强制恢复 scale = 1，攻击力恢复正常。
