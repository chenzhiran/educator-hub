敌人也是“对象”

在代码里，敌人 (Enemy) 和玩家 (Player) 本质是一样的，都是单位对象 (Unit Object)。

它也有自己的属性：

// 跑得快吗? unit.maxSpeed = 8; // 打人疼吗? unit.attackDamage = 100;
"敌人就是站在你对立面的、有速度和攻击力的小角色。"

生成器：刷怪机器

我们不需要一个个手动放敌人，用生成器 (Generator) 自动生产！

auto gen = game.spawnXY("generator", 40, 30); gen.spawnType = "scout"; // 产什么? gen.spawnDelay = 6; // 多久产一个?

spawnDelay = 6：大约每 6 秒刷一只新怪。

⚙️
点击机器刷怪
🧬

出生配置：onSpawn

刚出生的怪物是一张白纸，我们要用 onSpawn 来“培训”它。

auto onSpawn(auto event) { auto unit = event.target; // 设置为慢速但致命 unit.maxSpeed = 8; unit.attackDamage = 1000; }
"每当机器吐出一只新怪，就把它交给 onSpawn，赋予它属性。"
👶 ➡️ 🏋️‍♂️

一击必杀机制

如何让敌人“秒杀”玩家？

让敌人的攻击力等于（或大于）玩家的最大血量。

unit.attackDamage = player.maxHealth;

数学不等式：
Damage ≥ HP (One-hit Kill)

Player HP
💻

第23关：敌人配置

我们要生成一个生产“侦察兵”的机器，并让它们非常致命。

auto onSpawn(auto event) { auto unit = event.target; unit.maxSpeed = 8; unit.attackDamage = player.maxHealth; } int main() { auto generator = game.spawnXY("generator", 41, 31); generator.spawnType = "scout"; generator.spawnDelay = 6; game.setActionFor("scout", "spawn", onSpawn); return 0; }
