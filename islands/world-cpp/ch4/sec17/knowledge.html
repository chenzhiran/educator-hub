游戏开发六步法

Process

像真正的工程师一样思考：

1
定义 (Define): 一句话介绍玩法
2
设计 (Design): 画地图，列角色
3
实现 (Implement): 写代码！
4
测试 & 改进 (Test & Improve)

Tools

代码里的角色就像人物卡，有各种数值。

player.maxSpeed = 22; player.attackDamage = 100; game.score = 1000;

点号 (.) 用来查看或修改这些属性。

规则与触发器 (Functions & Events)

Tools

函数是“技能”，事件是“触发时机”。

// 定义规则(函数) auto onCollect(auto event) { game.score += 1; } // 绑定触发器(事件) player.on("collect", onCollect);
"当捡到东西(collect)时，就去执行加分规则(onCollect)。"

调整参数 (Balancing)

Step 5

游戏太难？太简单？调节参数常量！

auto HERO_SPEED = 20; auto OGRE_SPEED = 12; auto POWER_TIME = 4;

通过修改这些数字，找到“刚刚好”的乐趣。

实战步骤建议

Guide
  1. 地图布局：先用 spawnXY 铺好路和墙。
  2. 放置主角：spawnPlayerXY。
  3. 核心玩法：写 onCollect (加分) 和 onCollide (互动)。
  4. 加入敌人：用生成器，写 onSpawn (设置属性) 和 onDefeat (奖励)。
  5. 游戏循环：写 checkTime，管理倒计时和胜利条件。
  6. 最后打磨：试玩，改参数，写游戏说明。
