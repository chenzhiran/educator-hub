数据库 💾

Database

📝 永远记住你！
数据库 (db) 就像一个永久的笔记本。
它可以记录你玩了多少次、总共赢了多少局。哪怕你关掉电脑明天再来，数据还在！

// 胜利时的回调函数 (定义在 main 之前) void onVictory(auto event) { db.add("wins", 1); db.add("total defeated", game.defeated); } int main() { auto player = game.spawnPlayerXY("raider", 36, 30); game.addSurviveGoal(8); // 写入数据库：游玩次数 + 1 db.add("plays", 1); // 显示数据库记录 ui.track(db, "plays"); ui.track(db, "wins"); // 监听胜利事件 game.on("victory", onVictory); return 0; }
