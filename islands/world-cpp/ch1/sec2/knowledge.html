1. 程序 (Program)

THE HERO'S SCRIPT

01

📜 英雄的冒险剧本

程序就像给英雄写的剧本！
导演（你）告诉演员（计算机），每一步要做什么。
在 C++ 中，所有的剧本都必须写在 int main 里面。

int main() {
// 这是一个完整的C++程序
hero.moveRight();
hero.attack("Brak");
hero.moveRight(2);
return 0;
}

1.5 C++ 魔法框架

THE SKELETON

02

🏗️ 必须遵守的规则

1. int main() { ... }：
这是程序的"大门"，所有指令必须写在花括号里面。

2. 分号 ( ; )：
每一句指令结束都要加分号，就像写文章要加句号一样！

int main() { ← 魔法开始
// 你的代码写在这里
hero.moveRight(); ←
return 0; ←
} ← 魔法结束

2. 编程 (Programming)

WRITING THE SCRIPT

03
✍️

🎬 编写冒险剧本

编程就是编写剧本的过程！
你就像一个小导演，用代码语言（C++）写下英雄的每一个动作，创造出精彩的冒险故事。

int main() {
// 我正在"编程"...
hero.moveRight();
hero.attack("Treg");
return 0;
}

3. 注释 (Comment)

NOTES FOR HUMANS

04

📝 剧本的旁白说明

以 // 开头的文字。
计算机完全忽略它（看不见！），它是写给人类看的笔记，帮助理解你的意图。

🤖 "我看不到注释..."
// 使用名字击败食人魔 ← 旁白说明
hero.moveRight();
// 击败第一对食人魔
hero.attack("Sog");

4. 字符串 (String)

MAGIC QUOTES

05

✨ 带引号的魔法咒语

字符串就是被双引号包围的文字！
食人魔的名字都是字符串，引号告诉计算机：
“这是文字，不是代码指令哦！”

" Brak "
// 名字必须加双引号！
hero.attack("Brak"); 👈 字符串
hero.attack("Treg"); 👈 也是字符串
hero.attack("Kro");
hero.attack(Brak); ❌ 没引号，报错！

5. 顺序结构 (Sequential)

STEP BY STEP

06
// 1. 先向右移动
hero.moveRight();
// 2. 再攻击Sog
hero.attack("Sog");
// 3. 最后再移动
hero.moveRight(2);

像下楼梯一样，从上到下执行，不能跳！

6. Bug (程序错误)

ERROR IN THE SCRIPT

07

🐞 剧本里的小错误

Bug 就是程序出了错，就像剧本里写错了台词！
常见的 C++ 错误：
1. 忘记分号
2. 字符串忘记加引号

// 哎呀，这里有Bug！
hero.attack(Sog); ← 缺少引号！
// 计算机看不懂 Sog 是什么

7. 调试 (Debugging)

BUG HUNTING

08

🔍 抓虫子游戏

调试就是找出并修复 Bug！
程序员要像侦探一样，仔细检查代码，找到错误的地方并改正它。

点击右上角按钮开始修复代码！
hero.attack("Sog");
hero.attack(Gos); ← 虫子在这!
// 找到问题：缺少引号

📜 程序与编程

程序是指令组成的剧本；编程就是编写和修改剧本。

hero.moveRight();

📝 注释

写给人看的说明，不会指挥英雄行动。

// 先观察敌人的名字

💬 字符串

名字用引号包住，拼写和大小写要准确。

hero.attack("Brak");

🪜 顺序结构

先移动到合适位置，再攻击；按从上到下的顺序执行。

观察 → 移动 → 攻击

🐞 Bug

漏引号、拼写错误、行动顺序错误都可能出问题。

"Brak" ≠ "brak"

🔍 调试

运行观察 → 找到问题 → 修改 → 再运行。

hero.attack("Sog");

🏗️ main 框架

将动作写在关卡提供的 main 花括号内。

int main() { … }

🛑 分号

动作调用等语句末尾加分号。

hero.moveRight();

⚔️ 重复攻击

一次攻击不一定击败敌人，按关卡需要重复。

hero.attack("Brak");
hero.attack("Brak");
