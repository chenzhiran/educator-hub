0. 魔法框架 (Structure)

MAIN FUNCTION & RETURN

3 / 12

所有魔法的起源

int main() 就像是魔法书的封面。

大括号 { } 是"魔法结界"。所有的指令都必须写在结界里面，否则不会生效！

return 0; 代表"任务完成"。它通常放在代码的最后一行。

int main() {

  // 你的代码写在这里！
  hero.moveRight();

  return 0;
}

⚡ 技能与分号

方法 (Method) 就是主角会的技能！
小括号 () 代表“发招”。

每一句指令结束必须加上分号 ; 就像写句子要加句号一样！

3. 参数 (Parameter)

POWER LEVEL & DISTANCE

6 / 12

参数就像告诉技能要用多大的力气或走多远！
写在小括号 () 里面的数字就是参数。

情况 1: 没写参数

hero.moveRight();

默认只走 1 步

情况 2: 有参数!

hero.moveRight(3);

用力走 3 步！

7. 负数 (Negative)

BACKWARD!

10 / 12
👻

负数是小于零的数，前面有个减号 -。

🧙 对象

hero 是接收指令的英雄。

hero

⚡ 方法

点号连接对象与技能，小括号表示调用。

hero.moveRight();

🎯 参数

写在括号里，告诉技能走几步。

hero.moveRight(3);

🔢 整数

没有小数部分；负整数、0、正整数都是整数。

-2   0   3

📏 小数

带小数部分的写法，可表示更细的移动距离。

hero.moveRight(1.5);

🚀 正数与零

正数大于 0；0 既不是正数也不是负数。

1 > 0    0

⬅️ 负数

小于 0；本课向右移动传入 -2，表示反向移动。

hero.moveRight(-2);

🧭 四个方向

方法名大小写要准确；移动前先观察障碍。

moveRight / moveLeft
moveUp / moveDown

🏗️ 代码框架

保留关卡的 main 框架；动作语句以分号结尾。

int main() {
    hero.moveRight();
    return 0;
}
