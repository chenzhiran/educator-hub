🏗️ 1. C++ 魔法框架

THE SKELETON

01

C++ 的三条铁律

1. 大门：所有代码都要写在 int main() { ... } 里面。
2. 分号：每行命令结束必须加 ; (像句号一样)。
3. 注释：用 // 来写给自己看的笔记。

int main() {

    // 这是一个注释
    hero.moveRight(); ← 分号!
    hero.say("Hello");

    return 0;
}

综合运用

💬 3. 字符串与密语

第10–12关 · 注释、提示与字符串

03

"双引号的秘密"

字符串(String)：在 C++ 中，文字必须用双引号 " " 包起来。
例如密码 "Hush" 或敌人名字 "Two"。

注释(Comment)：用 // 开头。这是给程序员看的提示，计算机会忽略它。

int main() {
    // 这是一个注释提示
    hero.say("Hush");
    // 名字也是字符串
    hero.attack("Two");
    hero.attack("Two");
    return 0;
}

♾️ 4. while 循环初探

第13关 · 焰中舞动

04

永远重复的魔法

Loop (循环) 让你不用重复写代码。
while(true) 是一个无限循环。只要括号里是 true（真），里面的代码就会永远执行下去。
适合用来躲避一直发射的火球！

int main() {
    // 这是一个死循环
    while(true) {
        hero.moveRight();
        // 记得加分号！
        hero.moveLeft();
    }
    return 0;
}

📦 5. 循环体与花括号

第14关 · 闹鬼的迷宫

05

C++ 的“包裹”规则

在 C++ 中，我们用花括号 { } 来包裹要重复的代码。
被 { } 包起来的部分叫做循环体。
一定要确保命令写在花括号里面！

while(true) {
// --- 循环体开始 ---
hero.moveRight();
hero.moveRight();
hero.moveUp();
// --- 循环体结束 ---
}

🔎 找到一组动作

🔁 放入循环体

花括号包住这组动作；移动语句末尾加分号。

while (true) {
    hero.moveRight(2);
    hero.moveDown();
}

🏆 7. 最终挑战

第16关 · 概念挑战. 循环仓库

07

代码行数挑战

这一关要求代码不超过 5 条语句！
这强制我们必须使用循环。
如果你发现自己在重复写 moveUp, moveRight... 停下来，把它们放进循环里！

int main() {
    while(true) {
        hero.moveUp(2);
        hero.moveRight(2);
        hero.moveDown();
        hero.moveLeft();
    }
    return 0;
}
