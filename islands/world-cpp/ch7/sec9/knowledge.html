🧮 编写求和函数 (sumCoinValues)

我们需要写一个函数，专门用来算地上有多少钱。

// 定义函数，接收硬币数组作为参数
auto sumCoinValues(auto coins) {
    int coinIndex = 0;
    auto totalValue = 0;  // 💰 存钱罐初始为 0

    // 🔄 遍历每一个硬币
    while (coinIndex < coins.size()) {
        auto coin = coins[coinIndex];
        
        // ➕ 把硬币的价值加进存钱罐
        totalValue += coin.value;
        
        coinIndex++;
    }
    
    // 📦 把算好的总数返回出去
    return totalValue;
}

🧠 主逻辑：判断多少

拿到总数 goldAmount 后，和 104 做比较。

  • < 104: 不够 (Non satis)
  • > 104: 太多 (Nimis)
  • == 104: 完美 (Collect!)
while (true) {
    auto items = hero.findItems();
    
    // 📞 调用刚才写的函数
    auto goldAmount = sumCoinValues(items);
    
    if (goldAmount != 0) {
        if (goldAmount < 104) {
            hero.say("Non satis");
        }
        if (goldAmount > 104) {
            hero.say("Nimis");
        }
        if (goldAmount == 104) {
            collectAllCoins();
        }
    }
}
