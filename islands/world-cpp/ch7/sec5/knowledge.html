剧集比喻：季与集

嵌套循环就是：一个循环里面又套了另一个循环。

外层循环 (Outer)： 就像动画片的“第 1 季、第 2 季...”。
内层循环 (Inner)： 就像每一季里的“第 1 集、第 2 集...”。

每开始新的一季（外层跑一次），都要把那一季的所有集数看完（内层跑完），才能进入下一季。

基本结构 (Syntax)

while (外层条件) { // 外层做的事 while (内层条件) { // 内层反复做的事 do_something(); } }

注意缩进 (Indentation)！
多缩进一层的代码，就属于里面的循环。

任务一：打倒每个敌人

外层： 遍历敌人列表 (一个个点名)。
内层： 攻击当前敌人直到死。

while (index < enemies.size()) { auto enemy = enemies[index]; // 死磕到底! while (enemy.health > 0) { attack(enemy); } index++; }

嵌套循环 ≈ 乘法

如果有 3 个敌人，每个要打 4 下。

3 (外层) × 4 (内层)
= 12 次攻击

这就是为什么嵌套循环做事情特别多！要注意效率哦。
