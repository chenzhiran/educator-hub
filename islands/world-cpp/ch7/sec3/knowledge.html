什么是列表 (List)？

可以把它想象成：一排排好队的椅子。

每个椅子上坐着一个人（元素），每个椅子都有一个号码（索引）。

// C++ 中通常使用 vector 来表示动态列表 auto friends = {"Joan", "Ronan", "Nikita"};

大括号 {} 或函数返回的数组表示这是一个列表。

列表长度：size()

想知道队伍里有几个人？用 .size() 方法。

auto enemies = hero.findEnemies(); // 安全检查：确保有人再打 if (enemies.size() > 0) { auto first = enemies[0]; hero.attack(first); }

安全检查：只有当长度 > 0 时，才能去打第 0 个敌人。否则会扑空（报错）！

实时更新 (Update)

战场瞬息万变，每一轮循环都要重新“点名”。

while (true) { // 每一轮重新获取最新名单 auto neutrals = hero.findEnemies(); if (neutrals.size()) { hero.say(neutrals[0]); } else { hero.say("没人了"); } }
"不能拿着旧名单去点名，新同学可能刚进来，旧同学可能走了。"

遍历：挨个点名

用 while 循环加上 index 变量，可以把列表里的每个人都问候一遍。

int friendIndex = 0; // 只要索引小于总人数 while (friendIndex < friendNames.size()) { auto name = friendNames[friendIndex]; hero.say(name + ", go home!"); // 指向下一位 friendIndex += 1; }
