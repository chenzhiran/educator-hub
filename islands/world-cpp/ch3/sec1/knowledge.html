🏃 基础移动：moveXY

第2, 3, 5关

要让英雄移动，我们需要使用 C++ 的方法调用。

函数： hero.moveXY(x, y)

  • x: 目标点的水平位置。
  • y: 目标点的垂直位置。
// 示例：第5关 宝石果子 int main() { // 移动到宝石的位置 hero.moveXY(8, 48); hero.moveXY(12, 26); // 最后移动到红色 X 标记 hero.moveXY(74, 34); return 0; }
⚠️ C++ 重要规则： 每行代码结束必须加分号 ;

🔄 永恒的循环：while(true)

第4关：森林逃避

有时候我们需要英雄不停地做某件事（例如巡逻），这时就需要用到循环。

结构： while(true) { ... }

这叫做“无限循环”。只要条件是 true（永远是），大括号 {} 里的代码就会一遍又一遍地执行。

// 第4关：在树林间来回移动躲避猎头者 int main() { while(true) { hero.moveXY(56, 44); hero.moveXY(40, 56); hero.moveXY(24, 44); // 英雄会一直重复这几步 } return 0; }
🦸

📚 C++ 语法小贴士

1. 必须有的主函数

所有 C++ 程序都从 int main() { ... } 开始运行。你的代码要写在大括号里面。

2. 别忘了分号 ;

就像写文章要用句号一样，C++ 的每一句指令后面都要加分号！
hero.moveXY(10, 20); ✅

3. 参数与括号

函数需要用圆括号 () 包裹参数，多个参数用逗号 , 分隔。
buildXY("fence", 40, 20) 有三个参数。

常见错误 ❌

hero.moveXY(30, 30) // 缺少分号！ hero.buildXY('fence') // 单引号错误！应为 "fence" hero.moveXY 30, 30 // 缺少括号！
